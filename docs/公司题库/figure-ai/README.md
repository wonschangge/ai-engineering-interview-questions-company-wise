# Figure AI 面试题库

这一家的题有一个统一的前提：**每次试验都消耗机器人的时间，每次失败都有物理后果。**
这两个约束把"机器学习"变成了"资源分配"。

**第一件事是"数据与试验都比算力贵得多"。**
1,000 小时示范要 **5 万美元**，而训练只要 **200 美元——差 250 倍**；
所以"省算力"是错的优化方向。
而真机试验的样本量直接决定结论：**20 次试验的 CI 是 ±20 个点、400 次才是 ±4.5 个点**。
**这两条算术解释了为什么这一家的题总在问"你愿意花多少"。**

**第二件事是"分布差距有两种尺度"。**
**仿真与真机**的差距（域随机化 1.0× 时 78%、4.0× 时反而 41%）；
**实验室与现场**的差距（300 台里 45 台的成功率只有 34%，而总体是 75%）。
**两种尺度要用不同手段**：前者靠系统辨识与随机化，后者靠分层与 2×2。

**第三件事是"物理约束会反过来决定架构"。**
VLA 的延迟预算是 **10 ms**（而 LLM 是 3,000 ms，**差 300 倍**）；
7B 模型跑 100 Hz 要 **1.4 TB/s 的权重带宽，是机器人模块的 7 倍**——
所以**"慢模型跑 1 Hz + 快模型跑 100 Hz"不是设计偏好，而是带宽算术的必然**。
而 action chunking 把决策点数从 100 降到 10，**误差降到 1/100**。

准备这一家时，建议把**"每次试验/每小时的成本"**和**"带宽与延迟的算术"**这两条链练熟。
它们分别解释了"数据"与"架构"两侧的答案。

## 准备建议

1. **先把两条算术练熟**：**"1,000 小时 = 5 万美元 vs 训练 200 美元"**（05）与 **"20 次试验 ±20 点"**（07）。它们解释了这一家为什么总在问"资源怎么分"。
2. **01 与 12 是一对**：**01 讲"BC 为什么会崩"、12 讲"chunking 怎么修"**。两者的连接点是 **$T$ 出现在 $T^2$ 里**。
3. **02 与 08 是"两种尺度的分布差距"**：一个讲仿真与真机、一个讲实验室与现场。**两者都用"分层 + 消融"定位**。
4. **03 的奖励难题有四个可量化的理由**（稀疏 1 万回合、代理 +95%/真实 12%、重置 83 小时、长程信用分配）。**准备时按这四条讲，不要泛泛谈"奖励难设计"。**
5. **04 与 11 共享"带宽与延迟的算术"**：04 讲网络往返（376 ms，TTFT 占 80%）、11 讲权重带宽（1.4 TB/s）。**两者都是"物理约束决定架构"。**
6. **09 与 07 是一对**：**07 讲"评估时失败有后果"、09 讲"安全层把后果降到零"**。而安全层的第二重价值正是"降低评估成本"（6.6 万 → 6,600）。
7. **06 的结论最反直觉**：**"同任务拿到 0 小时"**。准备时要把"边际递减的斜率决定分配"讲清楚，否则听起来像在故意唱反调。
8. **10 是"概念题"但要给数字**：**延迟差 300 倍、数据差 6 个数量级、错误不可恢复**。三个数字比一段定义更有说服力。
