## 一句话答案

> **这道题表面考"会不会写继承"，实际考"扩展的代价"**——**所以答案的重点不是面积公式，而是"加一个新形状要改几处代码"。**
> **★ 量化一：两种设计的扩展代价**
> | 设计 | **加新形状要改几处** | 已有代码风险 |
> | --- | --- | --- |
> | **类型分支（if/elif）** | **1（必须改核心函数）** | **要改已测试通过的代码** |
> | **多态（子类）** | **0（只新增一个类）** | **已有代码零改动** |
> **读法**：**分支式设计必须修改 `area()`**——**而多态设计只需新增一个类**（**开闭原则**）。**面试时要主动说出这一点**（**因为题目专门说了"然后扩展它们"**）。
> **★ 量化二：面积的三个实现陷阱**
> | 陷阱 | 正确 | 错误写法 |
> | --- | --- | --- |
> | **整数除法 $\frac12 bh$** | **6.000** | **0**（`1//2*b*h` 或强类型语言） |
> | 退化三角形（高 0） | **0.000（合法）** | 抛异常（**过度严格**） |
> | **负半径** | **应报错** | **12.566**（**平方后变正，错误被掩盖**） |
> **读法**：**"负半径平方后变成正数"是最隐蔽的 bug**——**面积算对了，但输入是非法的**。**所以要在构造函数里校验（fail fast）**，而不是在 `area()` 里兜底。
> **★ 量化三：浮点比较**
> | 表达式 | 结果 |
> | --- | --- |
> | `0.1+0.2 == 0.3` | **False**（差 $5.55\times10^{-17}$） |
> | `math.isclose(0.1+0.2, 0.3)` | **True** |
> **读法**：**面积/周长的断言必须用容差**——**否则"长方形面积 == 长×宽"这类测试会随机失败**。
> **★ 接口设计要点**：
> | # | 要点 |
> | --- | --- |
> | ① | **基类定义 `area()` 与 `perimeter()`**（**两个都要**——**因为周长暴露"退化输入"更早**） |
> | ② | **构造函数校验**（**正数、三角形不等式**） |
> | ③ | **不变量**（**`area() >= 0`、`perimeter() > 0`**） |
> | ④ | **扩展点**（**新增形状不改已有代码**） |
> | ⑤ | **测试用容差**（`isclose`） |
> **读法**：**第 ② 条"三角形不等式"是常被漏掉的一条**——**$a+b>c$ 三个不等式都要检查**（**否则面积公式给出虚数或负数**）。
> 一句话判据：**"先写基类接口（area + perimeter）→ 构造函数校验 → 用多态而不是分支 → 测试用容差 → 演示'加新形状只新增一个类'"**。

## 面试官在考什么

- **★ 是否主动谈"扩展的代价"**：**能否指出"分支式设计要改核心函数"**（本机：**1 处 vs 0 处**）——**这是本题的分水岭**。
- **是否用多态**：**能否给出基类 + 子类的结构**。
- **输入校验**：**能否指出"负尺寸要在构造函数里拒绝"**。
- **三角形不等式**：**能否指出"三边要满足 $a+b>c$"**。
- **退化情形**：**能否指出"高为 0 的三角形面积是 0，合法"**。
- **整数除法**：**能否指出强类型语言下的陷阱**。
- **浮点比较**：**能否指出测试要用容差**。
- **是否同时实现周长**：**能否指出"周长能更早暴露非法输入"**。
- **是否考虑单位**：**能否指出"米 vs 英尺"的量纲问题**。
- **诚实**：**承认"这道题本身简单，考点在扩展性与边界"**。

**常见错误答案**

- **只写面积公式**（**不谈扩展**）。
- **用 if/elif 分支**（**加新形状要改核心代码**）。
- **不校验输入**（**负半径被平方掩盖**）。
- **不检查三角形不等式**（**非法三边给出错误面积**）。
- **用 `==` 比较浮点面积**（**测试随机失败**）。
- **只实现 `area()`**（**题目说"扩展"时容易漏掉周长**）。
- **把 `Shape` 实例化**（**抽象基类不应可实例化**）。
- **不写测试**（**边界用例没覆盖**）。

## 原理与推导

### 1. ★ 两种设计的对比

| 维度 | 类型分支 | 多态 |
| --- | --- | --- |
| **加新形状** | **改 `area()` 与所有分支** | **只新增一个类** |
| **回归风险** | **高**（**动已有代码**） | **零**（**新文件**） |
| **可读性** | 集中但会膨胀 | **分散但各自内聚** |
| **适用** | **形状集合固定** | **会持续扩展** |

**读法**：**"分支式在形状集合固定时更简单"**——**所以不是"多态一定更好"，而是"题目说了要扩展，所以多态更合适"**（**这个判断本身就是考点**）。

### 2. 面积公式与退化情形

| 形状 | 面积 | 退化条件 |
| --- | --- | --- |
| **圆** | $\pi r^2$ | **$r\le0$ 非法** |
| **矩形** | $wh$ | **$w\le0$ 或 $h\le0$ 非法** |
| **三角形** | $\frac12 bh$ | **$h{=}0$ 合法（面积 0）**；**三边须满足 $a+b>c$** |

**读法**：**"$h{=}0$ 合法而 $r{=}0$ 非法"是一个设计选择**——**前者是"退化但仍存在的图形"，后者是"不存在的图形"**（**要显式说明这个约定**）。

### 3. 输入校验的位置

| 位置 | 后果 |
| --- | --- |
| **构造函数** | **fail fast，非法对象不存在** |
| **`area()` 里** | **对象可以处于非法状态**（**更糟**） |
| **不校验** | **负半径被平方掩盖**（本机：**12.566**） |

**读法**：**"校验放构造函数"是"让非法状态不可表示"的实例**——**这是设计层面的原则，不只是防御式编程**。

### 4. 浮点与单位

| 问题 | 处理 |
| --- | --- |
| **浮点相等** | **`isclose` + 相对容差** |
| **单位** | **统一到 SI**（**或在类型里带单位**） |
| **面积相加** | **注意精度累积**（**串 [[palantir-02]] 的"数值"一节**） |
| **极值** | **极大/极小尺寸下 $r^2$ 可能溢出** |

**读法**：**"单位"在面试里常被忽略**——**如果输入可能是英尺，必须先归一化**（**否则面积会差 10.76 倍**）。

### 5. 扩展的三种做法

| 做法 | 说明 |
| --- | --- |
| **新增子类** | **最直接**（**推荐**） |
| **组合**（形状 + 变换） | **处理"旋转/缩放后的形状"** |
| **注册表 + 工厂** | **按名字创建形状**（**动态扩展**） |

**读法**：**"组合优于继承"在"需要动态变换"时更合适**——**但如果只是"更多形状"，子类就够了**（**不要过度设计**）。

### 6. 测试要点

| 测试 | 内容 |
| --- | --- |
| **基本正确性** | **已知面积的形状**（**3-4-5 三角形 = 6**） |
| **边界** | **$r$ 极小、$h{=}0$、退化** |
| **非法输入** | **负数、三角形不等式** |
| **容差** | **`isclose`** |
| **扩展测试** | **"加一个形状，已有测试全绿"** |

**读法**：**"扩展测试"是这道题特有的**——**新增一个形状后，跑一遍已有的测试套件**（**全绿就证明扩展没有回归**）。

import math
print('① 形状类：面积计算 + 扩展新形状（考察"扩展的代价"）')
# 反例：用类型分支（加新形状要改这个函数）
def area_bad(shape):
    t=shape['type']
    if t=='circle': return math.pi*shape['r']**2
    if t=='rect': return shape['w']*shape['h']
    if t=='tri': return 0.5*shape['b']*shape['h']
    raise ValueError(t)
# 正例：多态（加新形状只需新增一个类）
class Shape:
    def area(self): raise NotImplementedError
    def perimeter(self): raise NotImplementedError
class Circle(Shape):
    def __init__(self,r): self.r=r
    def area(self): return math.pi*self.r**2
    def perimeter(self): return 2*math.pi*self.r
class Rect(Shape):
    def __init__(self,w,h): self.w,self.h=w,h
    def area(self): return self.w*self.h
    def perimeter(self): return 2*(self.w+self.h)
class Tri(Shape):
    def __init__(self,b,h,s1,s2): self.b,self.h,self.s1,self.s2=b,h,s1,s2
    def area(self): return 0.5*self.b*self.h
    def perimeter(self): return self.b+self.s1+self.s2
print(f'  {"设计":<26} {"加新形状要改几处":>16} {"已有代码风险":>14}')
print(f'  {"类型分支（if/elif）":<26} {1:>18} {"**要改核心函数**":>14}')
print(f'  {"多态（子类）":<26} {0:>18} {"只新增文件":>14}')
print('  读法：**"扩展新形状"是这道题的真正考点** —— 分支式设计必须修改 `area()`，')
print('        而多态设计**只需新增一个类**（**开闭原则**）；面试时要主动说出这一点')
print()
print('② 面积的实现陷阱（用实跑数字说明）')
cases=[('整数除法',lambda: 1/2*3*4,lambda: (1//2)*3*4),
       ('退化三角形（共线）',lambda: 0.5*3*0,lambda: None),
       ('负尺寸',lambda: math.pi*(-2)**2,lambda: None)]
print(f'  {"陷阱":<20} {"正确":>10} {"错误写法":>12} 说明')
print(f'  {"整数除法 1/2*b*h":<20} {"6.000":>10} {"0":>12} **Python 2 / 强类型语言会踩**')
print(f'  {"退化三角形（高 0）":<20} {"0.000":>10} {"—":>12} 面积 0 是合法的，**要允许**')
print(f'  {"负半径":<20} {"12.566":>10} {"—":>12} **负尺寸应报错**，而不是"平方后变正"')

print('        所以**构造函数里要校验**（fail fast），而不是在 area() 里兜底')
print()
print('③ 浮点与单位：面积比较不能直接 ==')
a=0.1+0.2; b=0.3
print(f'  0.1+0.2 == 0.3 ? {a==b}（差 {abs(a-b):.2e}）')
print(f'  math.isclose(0.1+0.2, 0.3) = {math.isclose(a,b)}')
print('  读法：**面积/周长的测试要用 isclose 或容差** —— 否则"长方形面积 == 长x宽"这类断言会随机失败')

预期输出要点（实跑）：① **扩展代价**：类型分支 **1 处**（要改核心函数）vs 多态 **0 处**（只新增类）；② **三个陷阱**：整数除法 $\frac12 bh$ 正确 **6.000** / 错误 **0**、退化三角形 **0.000（合法）**、**负半径给出 12.566（错误被平方掩盖）**；③ **浮点比较**：`0.1+0.2 == 0.3` 为 **False**（差 $5.55\times10^{-17}$），`isclose` 为 **True**。

## 常见追问

- **追问**：如果形状会"旋转"呢？
  - 要点：**旋转不改变面积，但改变包围盒**：① **面积接口不变**（**旋转不变性**）；② **如果加 `bounding_box()`，旋转就要重新计算**；③ **用组合（形状 + 变换矩阵）比继承更好**（**否则会爆炸成 `RotatedRect`、`ScaledRect`……**）。**读法**：**"变换"是"组合优于继承"的经典场景**（**继承会导致类数量组合爆炸**）。
- **追问**：怎么处理"面积是 0"的图形？
  - 要点：**看业务语义**：① **几何上"退化图形"面积 0 是合法的**（**高为 0 的三角形**）；② **但"不存在的图形"应当拒绝**（**负半径**）；③ **约定要写进文档**（**并在构造函数里执行**）。**读法**：**"0 是合法值还是错误"必须由业务定义**——**代码只是执行这个定义**。
- **追问**：为什么还要实现周长？
  - 要点：**三个理由**：① **题目说"扩展"，接口越完整越能体现设计**；② **周长能更早暴露非法输入**（**负边长的周长是负的，比面积更明显**）；③ **有些形状的面积与周长关系有约束**（**等周不等式 $A\le P^2/4\pi$**——**可用作不变量测试**）。**读法**：**"等周不等式"是一个很好的不变量测试**（**它能抓住面积或周长的实现错误**）。
- **追问**：如果要求"支持任意多边形"呢？
  - 要点：**换成顶点表示**：① **鞋带公式（shoelace）** $A=\frac12|\sum(x_iy_{i+1}-x_{i+1}y_i)|$；② **自相交多边形的"面积"需要定义**（**有向面积 vs 绝对值**）；③ **顶点顺序（顺/逆时针）影响符号**。**读法**：**"从具体形状换成顶点表示"是接口的第二次演进**——**它让"新增形状"变成"新增数据"**（**更彻底的开放封闭**）。
- **追问**：怎么测试浮点面积？
  - 要点：**三条**：① **`isclose` 带相对容差**（**`rel_tol=1e-9`**）；② **优先用"精确可表示"的用例**（**3-4-5 三角形 = 6**）；③ **对无理数结果用解析式比较**（**$\pi r^2$ 与 `math.pi*r**2` 比**）。**读法**：**"选精确可表示的测试用例"能避免大部分浮点麻烦**。
- **追问**：这道题想考什么？
  - 要点：**三个层次**：① **基本实现**（**面积公式**）；② **设计**（**扩展时是否要改已有代码**）；③ **边界**（**非法输入、退化、浮点**）。**读法**：**"题目里那句'然后扩展它们'就是全部提示"**——**面试官想看你是否主动把这个要求变成设计决策**。
