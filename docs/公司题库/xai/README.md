# xAI 面试题库

这一家的题有一个鲜明特点：**几乎每道题都要求你先「算清楚」再动手**——
KV 要算容量与带宽、限流器要算预扣与超发、goodput 要算检查点与回滚、
去重要算 Bloom 与 LSH 的内存、系统设计要算嵌入算力与索引重建、
连「四小时做演示」都要算成功率的乘法结构。

准备这一家时，建议把**「先量化，再决策」**当成口头禅：
**先给公式与量级，再说选哪个方案、以及为什么**。
这一家的面试官明显更在意「你怎么得出结论」，而不是「你知不知道某个技术名词」。

## 这家公司的面试怎么准备

**第一，每道题都先给公式或量级。** 这一家的题几乎都有「可算的核心」：
KV 的 $2n_{\text{kv}}d_h L b$、限流器的「预扣 vs 误拒」、检查点的 $T^\*=\sqrt{2C\,\text{MTBF}}$、
Bloom 的 $-\frac{n\ln\varepsilon}{(\ln 2)^2}$、LSH 的 $1-(1-J^r)^b$、演示成功率的 $\prod p_i$。
**先写公式，再给数字，最后说选哪个**——这是这一家最认的表达顺序。

**第二，注意「第二关」。** 这一家的题反复在考「你只算了第一关吗」：
KV 不只算容量还要算**带宽**、限流不只算配额还要算**原子性**、goodput 不只算检查点还要算**重启**、
去重不只算精确还要算**近似**、系统设计不只算服务侧还要算**摄取侧**。
**每答完一层，主动问自己「还有哪一层没算」。**

**第三，编码题要给出「可验证的正确性」。** 两道硬编码题（01、02）都不是「写出来就行」：
**01 用差分测试、02 用计数包装证明惰性**——**主动给出验证方法**比多写代码更加分。
第 03 题更是直接考「没有规格时你怎么建立可信度」。

**第四，行为题也要有量化。** 第 10 题用**乘法结构**说明了「为什么不能全用来开发」——
**这一家的行为题同样期待你用数字支撑判断**，而不是讲一个励志故事。
