# Waymo 面试题库

这一家的题有一个统一的主线：**这个系统的正确性无法用"跑够里程"来证明。**
碰撞每百万英里只有 1 次、致死每百万英里只有 0.01 次，
而"零事件"给出的上界是 $3/n$——**要证明"碰撞率 < 1/百万"需要 300 万英里，要证明"致死率 < 0.01/百万"需要 3 亿英里。**
**所以整个题库都在回答"在证明不了的情况下，怎么论证"。**

**第一件事是"指标本身可能是错的"。**
**脱离接管率测的是安全员的容忍度而不是系统的属性**，而且它可被优化（去简单路开就下降）；
**minADE 会奖励"撒网"**——纯随机模态在 K=100 时也能把 minADE 从 6.204 降到 2.204、把 miss rate 从 1 刷到 0；
**而"急刹 +15%"按相关性换算到碰撞风险只有 +7.5%，远低于噪声。**
**三道题分别拆掉了三种指标。**

**第二件事是"证据的量级是算出来的，不是感觉出来的"。**
仿真 1 亿英里 × 1 美分、路测 10 万英里 × 5 美元；
6 亿个片段的嵌入只要 0.6 TB（而原始日志 1 EB）；
**而"先过滤再嵌入"把成本从 3.3 万美元降到 333 美元。**
**这些数字决定了系统长什么样。**

**第三件事是"约束会反过来决定架构"。**
算术强度阈值 = 250 TOPS / 200 GB/s = **1,250 FLOPs/byte**，而 batch=1 的 decode 只有 **2**——
**所以"堆 TOPS 没用"**，而且模型翻倍时**先坏的是内存带宽（60% → 120%）而不是算力（40% → 80%）**；
VLM 比驾驶回路慢 20 倍，所以**它只能待在车外**。

准备这一家时，建议把**"三次法则"**、**"算术强度"**、**"多重比较"**这三条算术练熟。
它们分别解释了"证据够不够"、"算力行不行"、"信号真不真"。

## 准备建议

1. **先把三条算术练熟**：**三次法则**（09）、**算术强度**（05）、**多重比较**（11）。它们分别回答"证据够不够"、"算力行不行"、"信号真不真"。
2. **01 与 03 是一对**：**01 讲"怎么算"、03 讲"该算什么"**。而 03 的核心洞察正是"01 算出来的那个指标会奖励撒网"。
3. **02、08、09 是"可论证性"三部曲**：**02 讲架构决定可论证性、08 讲论证怎么组织、09 讲证据怎么量化**。三家一起看才能理解"为什么模块化不是性能选择"。
4. **06、07 是"漏斗的两级"**：**06 讲七级漏斗、07 讲其中的"嵌入检索"那一级**。注意两者的成本算术是一致的（先廉价过滤）。
5. **09、10、11 是"评估三部曲"**：**09 讲指标、10 讲工具可信度、11 讲决策**。顺序不能反——**先问仿真器可不可信，再问信号真不真**。
6. **05 与 04 共享"预算"这条线**：**05 给出 100 ms 的回路预算、04 说明 VLM 的 2,000 ms 为什么进不去**。
7. **12 的论证方式值得单独学**：它用"失效模式矩阵"而不是"性能对比"来论证多模态的必要性——**这是"用独立性论证冗余"的范例**。
8. **11 的答法最值得模仿**：**在信息不足时不要急着做决定，而是先问三个能把问题变清楚的问题。**
