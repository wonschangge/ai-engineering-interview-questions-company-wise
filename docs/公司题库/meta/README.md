# Meta 面试题库

这是公司题库里题量最大的一家，也最能体现 Meta 的面试风格：**代码题扎实、系统设计全落在自家产品上（信息流 / 广告 / Story / Marketplace / 翻译）、
并且一定会问「上线之后怎么维护、指标怎么证明」**。二十六道题里，实现题与系统设计题各占三分之一，行为题三道——比例本身就是信息。

## 这家公司在考什么

四条主线，几乎每道题都落在其中一条上：

1. **实现与复杂度**（01–08）：题目不偏门，但要求边界清晰、复杂度明确、能现场验证；`07` 还要求你知道「生产里为什么不用回溯」。
2. **规模与成本**（11、12、16、17、23）：大是这里的默认前提，答题必须落到**显存、带宽、延迟、钱**上，而不是「加机器」。
3. **产品闭环**（15–20、21、22）：每道系统设计都带一个「怎么衡量、怎么防退化」的尾巴——这是 Meta 面试最稳定的特征。
4. **协作与文化**（24–26）：讲做成、讲做错、讲运维与动机；共同要求是**可核查**与**机制化**。

## 建议学习顺序

- **面试前一天**：`10 → 12 → 16 → 17`（模型 → 服务 → 信息流 → 广告）。这四题是 Meta 面试的高频组合，且共用「规模化取舍」的表达方式。
- **实现题**：`01 → 06 → 07 → 08`，从热身到有深度的 DP 与生产陷阱。
- **系统设计全览**：`15 → 16 → 18 → 19 → 20`，看同一套漏斗骨架如何在不同产品上变形。
- **行为题**：`24 → 25 → 26` 一起准备，共用同一批项目素材（一个成功案例 + 一个失败案例 + 一次事故）。

## 自测清单

- 不用除法、$O(1)$ 额外空间求「除自身以外乘积」怎么做？边界（含零）怎么处理？
- 最小窗口的双指针收缩条件是什么？为什么不能逐字符比较两个计数表？
- 二叉树序列化怎么保证可逆？空哨兵为什么必要？
- 中序转链表时，`prev` 与 `dummy` 各解决什么问题？
- 外星人词典的建图规则是什么？什么情况下输入本身非法？
- 「K 近点 / 前 k 高频 / 会议室」三题的选择策略分别是什么？复杂度各是多少？
- 正则 DP 里 `*` 的两种转移分别往哪个方向走？生产里为什么用 NFA 模拟而不是回溯？
- 流式 top-k 的口径为什么必须提前写死？堆方案在生产里会因为什么失效？
- AUC 与校准分别衡量什么？为什么计费系统必须校准？温度缩放怎么校准？
- Llama 相对 2017 原版的四项改动是什么？各自解决什么问题？
- 从 8 卡到数千卡，四层失效分别是什么？各自的典型对策？
- 70B 服务栈的六跳是什么？成本主要花在哪两项上？
- 在陌生代码库里，你第一步做什么来「锁定判据」？
- post-training 的全局层与个人层分别放什么？个性化怎么防遗忘？
- Feed 排序四层漏斗的目标函数分别是什么？位置偏差的三种处理方式？
- 广告的 eCPM 怎么算？pacing 解决什么问题？ghost ads 相比 holdout 的优势是什么？
- Story 为什么是两级排序？24 小时生命周期带来哪些连锁后果？
- 端到端分类里，人审预算如何决定阈值与风险敞口？
- BLEU 衡量什么、不衡量什么？术语约束该在哪一层实现？
- 发布门禁里硬门、软门、构建门分别管什么？为什么样本量 200 时 3 个百分点的差异不可信？
- 1% 违规基率下，「99.9% 准确率」意味着多少漏放与误杀？
- 视频相对图像，多出来的四个工程问题是什么？token 守恒式怎么写？
- 讲项目时，价值链四段与障碍四分类分别是什么？
- 一次判断错误，你要说清的六个字段是什么？
- 生产 ML 流水线的六块环节与各自失效模式是什么？告警为什么要按误报率标定？
