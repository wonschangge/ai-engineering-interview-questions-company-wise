## 一句话答案

> 把它定性成**代理目标失配 + 拍卖机制**，而不是「AUC 不准」：AUC 只看正负样本的相对排序，对任何严格单调变换不变，也不是 proper scoring rule，所以「AUC 涨、校准差」不矛盾——只报 AUC 等于只报了一半信息。
> 广告链路里排序分（出价 × pCTR）决定名次，计费价却只付「刚好压过第二名」：$\text{cpc}_1 = b_2\hat p_2/\hat p_1$，分母是**自己预测的 pCTR**。赢家一侧被高估就直接把计费基数压下去。5 万次重放实测：排序改善单独值 +11.48% 收入，同一套链路误差单独扣 −7.87%，合起来 −1.44%（落在实验噪声内），而分配准确率从 68.50% 升到 80.77%。
> 裁决顺序固定：① 复算口径与配对检验（相对还是绝对、测试集多大、是否 DeLong 配对）；② 拆漏斗与分桶（量、价、赢家 pCTR 谁动了）；③ 改指标与门禁（价值加权 log loss/Brier + 校准阈值，拆开排序链路与计费链路）；④ 最后才回滚模型。
> 「收入持平」必须先排除欠功效：收入是重尾指标，CV = 3 时检出 0.5% 的变化要 565 万用户/臂。

## 面试官在考什么

- **定性能力**：能不能一句话说成「代理目标失配 + 拍卖机制」，而不是把 AUC 与校准当成同一把尺子。题面来自 README.zh-CN.md 中 Meta 的「机器学习与深度学习基础」一节（覆盖 MLE E4–E7、Research Engineer、Applied Research Scientist 等岗位），该节记录的流程是技术初筛 45 分钟 2 道编程题 → onsite 两轮编程 + 一轮 ML 系统设计 + 一轮 ML 领域/广度 + 行为面（Jedi）；这题考的是判断顺序，不是定义背诵。
- **正交性内行知识**：AUC 对严格单调变换不变（$\hat p \to 1.2\hat p$ 一动不动）、AUC 不是 proper scoring rule、不惩罚系统性高估；必须同时报 log loss、Brier、ECE 与可靠性图。
- **拍卖机制**：第二价格式下计费由「第二名 + 自己的 pCTR」决定，能写出计费公式并推出「校准误差 → 计费基数」；还要分清纯全局缩放（在二价里干净约掉、不伤收入）与幅度不一致的相对误差（真正的收入杀手）。
- **统计纪律**：DeLong 配对检验、A/A 水位、MDE 反推样本量、SRM、随机化单位的设计效应、连续窥视、转化延迟，口径与 [[evaluation-09]] 同一套。
- **落地顺序**：先复算、再归因、再改指标，最后才回滚；校准只能在时间留出集上拟合，且计费链路的修正不能动排序链路。

常见错误答案：

- 「AUC 涨了收入就该涨，实验肯定跑错了」——没提正交性，也写不出计费公式，「为什么偏偏是校准」一个字都答不出。
- 「校准差就上 isotonic」——在训练分布上拟合、直接替换排序链路；isotonic 会破坏严格单调、把刚拿到的排序收益一起改坏，正确做法是只把它用在计费链路上并设最小样本量。
- 「收入持平就是没影响」——不查 MDE、SRM、设计效应与转化成熟度，把一个本来检不出 1% 的实验当成结论。

## 原理与推导

### 1. 先钉口径：+2% 的分母、测试集与配对检验

同一句 +2% 至少有三种读法，先问清分母：相对 AUC 提升 2%（AUC 0.80 → 0.816，绝对 +0.016）、绝对提升 2%（0.80 → 0.82，相对 +2.5%）、或这 2% 指的其实是线上点击率或 log loss——那是别的量。前两种读法的效应量差 1.25 倍，落到样本量上就是 1.56 倍（$\Delta^{-2}$）。紧接着要钉测试集口径：哪个人群与版位、时间切分是否与线上一致（按时间留出还是随机留出）、候选池是否与线上一样大、标签是否成熟。

**在同一个测试集上比较两个模型必须用 DeLong 配对检验。** 用两条独立的 95% 置信区间「有没有重叠」来判断会白扔检出力。Hanley–McNeil 单模型标准误：

$$\mathrm{SE}(A)=\sqrt{\frac{A(1-A)+(n_+-1)(Q_1-A^2)+(n_--1)(Q_2-A^2)}{n_+n_-}},\qquad Q_1=\frac{A}{2-A},\quad Q_2=\frac{2A^2}{1+A}$$

取 $A=0.80$（$A(1-A)=0.16$、$Q_1=0.6667$、$Q_2=0.7111$），80% 功效的可检出幅度是 $2.8016\,\mathrm{SE}$：测试集 $n_+=n_-=1{,}000$ 时 $\mathrm{SE}=0.00989$，只能检出约 3.46% 的相对差异；10,000 时 1.10%；100,000 时 0.35%（表 1）。所以小测试集上的 +2% 可能整个落在噪声里。配套动作是 A/A 水位：同一版本隔周重跑 20–30 次，取离线差值绝对值的 95 分位作为真差异下限，增量必须显著超过水位才算提升（[[consumer-ml-02]]）。

### 2. AUC 与校准是正交的两个维度

AUC 只统计正负样本对的相对顺序，校准问的是「预测 0.05 的那批里实际是不是 5%」。三个直接后果：

1. 把 pCTR 整体乘 1.2、做 $p \to p^{0.8}$、或对 logit 做放大，AUC 逐位不变，可靠性图完全变形——本机三种单调变换的 AUC 差都是 `0.0e+00`。
2. AUC 不是 proper scoring rule，系统性高估不受惩罚；只有 log loss、Brier 与校准误差管这件事。
3. 单一 AUC 无法区分「排序变好」与「概率变准」，所以必须同时报四类口径：proper scoring rule（log loss、Brier）、校准（$\mathrm{ECE}=\sum_b \frac{n_b}{n}|\overline{\hat p}_b-\bar y_b|$，连分箱方式与箱数一起写）、分位桶的预测/实际比值与校准斜率截距（理想 $a=1,b=0$）、以及**时间留出集**（校准随时间漂移，用旧窗口拟合的映射在新流量上必然偏）。

诊断拆成三问：整体偏多少？分桶偏在哪（版位 × 人群 × 广告主规模，哪个桶被高估）？**单调性有没有被破坏**——破坏排序的校准误差最贵，因为它同时改了拍卖名次。

本机复算（40 万样本、后 40% 时间留出）：新模型 AUC 0.73588 → 0.75354（+2.40%），但 ECE 0.0515 → 0.2416、log loss 0.6045 → 0.7686、Brier 0.2088 → 0.2643；对同一个排序分做 Platt 重校准（冻结排序）后 AUC 与前一行逐位相同（0.753538），log loss 降到 0.5875、ECE 降到 0.0411。**排序与概率是两条可以分开修的链路。**

ECE 的分箱口径必须一起报：偏差是分数的单调函数时，等频分箱几乎不受箱数影响（5/10/50/300 箱 = 0.2416/0.2416/0.2416/0.2417）；而局部偏置型（高分段 5% 再高估 0.30）同一份预测在 5 箱与 300 箱之间差 2.2 倍（0.0066 → 0.0145）。只报一个数，等于替读者选了分箱。

### 3. 校准误差怎么穿过拍卖变成收入

广告拍卖按 $\text{score}_i = b_i\hat p_i$（转化目标再乘 pCVR）排名，赢家按「刚好压过第二名」计费：

$$\text{cpc}_1=\frac{v_2}{\hat p_1}=\frac{b_2\hat p_2}{\hat p_1},\qquad \text{平台收入}=\text{cpc}_1\times\text{实际点击},\qquad \text{广告主价值}=b_1\times\text{实际点击}$$

**通道一，计费折扣。** 分母是自己预测的 pCTR，赢家被高估就少收钱。这里必须说精确，否则会把缩放不变性讲反：纯全局常数缩放 $\hat p \to c\hat p$ 在二价里干净约掉（名次不变、$v_2/\hat p_1$ 不变）——本机把新模型逐点乘 0.9，收入差 `0.000e+00` 美元、AUC 差 `0.000e+00`；真正伤收入的是**与价值相关的相对误差**：只有部分广告主或只有高分段被高估、logit 被放大（过自信）时，赢家与次名的比值被改变，计费基数被下压。所以「同向高估压低收入」要讲成「幅度不一致或随分数放大的同向高估」，纯全局上浮只会出现在校准报告里。

**通道二，分配错位与预算消耗。** 被高估的桶抢量、被低估的桶饿死，预算花在低价值流量上。这类损失在 1–2 周的收入上看不见：广告主预算是硬约束时，平台短期收入 ≈ 花掉的预算，损失落在广告主侧的 ROAS/CPA、预算花完率与竞得率上——所以要广告主级与价值侧护栏，而不只是总收入。

**通道三，反馈回路。** pCTR 驱动曝光，曝光又决定下一轮训练数据；被高估的桶拿到更多曝光后正例率被曝光机制污染，偏置自我强化。慢漂移只在长期 holdback（永久保留约 1% 对照流量）里看得见。

再叠两条结构性偏差：训练点击受展示位置影响，评测集不按位置去偏则离线增益不可兑现（[[consumer-ml-03]]）；双边市场溢出（广告主预算跨版位共享、同批广告主在两臂里互相竞价）违背 SUTVA，随机化单位必须是用户/广告主级而不是请求级（[[consumer-ml-02]]）。

本机按这条链路做了 5 万次重放（表 4）。把「排序更好」与「链路更差」拆开，是两条方向相反的力：排序单独值 **+11.48%** 收入，同一套链路误差单独扣 **−7.87%**，合起来 **−1.44%**（落在噪声内，正是题面的「收入持平」）。2×2 消融的主效应是排序 +8.96pp、校准 −10.39pp、交互项 −5.04pp——三个数不能简单相加，这也是必须做消融、不能只报总收入的原因。

最容易漏的一条：**日志口径的校准看着没问题，服务口径已经烂了。** 基线模型在全部曝光上 ECE = 0.00499，但真正决定计费的竞得曝光上，赢家平均高估 27.6%（新模型 112.9%）。挑选效应（竞得者是噪声实现的极大值）会在服务分布上放大偏差，所以校准要按「是否竞得 / 名次」分桶报，不能只报全量日志。

### 4. 在线侧先排除「测不出来」和「测错了」

收入是重尾连续指标，每臂样本量 $n = 15.70\,\sigma^2/\Delta^2$（$\alpha=0.05$ 双侧、power 80%，[[evaluation-09]]）；写成相对口径 $n = 15.70\,CV^2/r^2$，$r$ 为相对提升：CV = 1/3/5 时，检出 0.5% 要 0.63M/5.65M/15.70M 用户每臂，检出 1% 要 0.16M/1.41M/3.93M（表 5）。**「收入持平」的第一解释往往是欠功效**：先用实验的真实样本量反算 MDE 再下结论，而不是写「无影响」。

其余必查项：SRM（百万级流量下单臂 0.165pp 的失衡即 $\chi^2=10.82$、$p=0.0010$，阈值取 0.001 而不是 0.05，因为它每个实验天天跑）；随机化单位与指标粒度不一致（按用户随机、按请求统计，$\rho=0.2$、$\bar m=4$ 时等效样本只剩 $n/1.6$，MDE 乘 1.265）；连续窥视把 5% 的名义假阳率抬到约 10%，要么事前定样本量到期判读、要么用序贯检验；延迟转化与归因窗口（7–30 天的转化让实验期标签不成熟，两臂成熟度还可以不同）；时长 ≥ 7 天覆盖完整周期，看稳态而非首日峰值。

最后是漏斗分解：请求 → 候选 → 竞得 → 曝光 → 点击 → 转化 → 收入，逐档看是哪一项动了。只报总收入，等于把「CTR 涨、单价跌」这类互相抵消的组合平均掉（子集加权和的思路见 [[consumer-ml-02]]）。

### 5. 代理标签失配与离线管道口径

离线标签是「曝光后是否点击」，业务目标是收入或转化价值，这就是 $m\neq u$ 的教科书形态（[[evaluation-05]]）：AUC 由大量易分负例主导，而**决定拍卖名次转换的边际排序**（候选池顶部几个之间的 swap）反而可能变差。替代与补充指标三条：

1. 价值加权的 log loss 与校准误差，对齐计费口径而不是对齐「能不能分开」；
2. 基于日志的反事实收入估计 IPS/SNIPS，前提是日志里记了 propensity——不记，这批日志以后永远做不了反事实评估；
3. 历史发布回测「离线 $\Delta$ × 线上 $\Delta$」的相关性与斜率，相关性低就换指标，而不是继续刷它。

管道口径还有五处必查：负例下采样改变先验（AUC 稳态不变，但 pCTR 必须先做先验校正再进拍卖：负例按 $1/r$ 抽样时 $\mathrm{logit}\,\hat p \to \mathrm{logit}\,\hat p-\ln r$，$r=10$ 就是减 2.3026）；训练/服务偏斜；用到了决策时刻之后才产生的特征或标签；离线候选池比线上更全；离线时间窗比线上更宽。本机复算：真实域平均预测 0.5001 / 实际 0.4958，1:10 负例采样域平均预测 0.9084 / 实际 0.9078，两域 AUC 都是 0.7325–0.7329——**只看 AUC 完全发现不了先验口径错了**。

### 6. 落地动作清单（按成本从低到高，每条都能回滚）

1. **先不动模型**：复算口径（相对/绝对、测试集、标签成熟度）+ DeLong 配对检验 + A/A 水位，判断 +2% 是否过水位。
2. **出一份校准报告**：整体 / 分位桶 / 版位 × 人群 × 广告主规模，含 log loss、Brier、ECE（连分箱方式与箱数）、斜率与截距，全部在时间留出集上算。
3. **拆链路**：排序可以用任意单调变换不变的分数；计费、出价与预算消耗必须用校准过的概率。修正用 Platt（参数少、稳）或 isotonic（灵活、会过拟合并破坏严格单调，只能用在计费链路上），在**近期**留出集上按 版位 × 优化目标 × 广告主规模 分段拟合，每段设最小样本量，并配单调性与逐桶校准检查。
4. **门禁同时挂两套阈值**：proper scoring rule 与校准误差，不允许「AUC 涨了就放行」（分层测试集、事前阈值与 flaky 水位的设计见 [[evaluation-04]]）。
5. **在线实验继续跑但改口径**：拉长到覆盖转化成熟期；加广告主级与价值侧护栏（ROAS/CPA、预算花完率、竞得率、单位曝光价值）；用影子流量在零收入影响下比对两版 pCTR 与计费口径；开 1% 长期 holdback；判据事前注册。
6. **若校准修正后收入仍不涨，就据实给出「这次离线增益不兑现」的结论，并回头修改离线主指标**。刷高一个与收入无关的代理指标是这类岗位最常见的失败模式，机制上与 [[evaluation-05]]、The Leaderboard Illusion 讲的榜单失真是同一件事。

代码块 1（表 1、表 2、单调变换不变性）：

```python
import math
import numpy as np

rng = np.random.default_rng(20260928)
N = 400_000
s = rng.normal(0, 1, N)
g = (rng.random(N) < 0.5).astype(int)
t = np.arange(N) / N
p_true = 1 / (1 + np.exp(-(s + 0.75 * g - 0.80 * t)))     # 分桶位移 + 时间漂移
y = (rng.random(N) < p_true).astype(int)
te = slice(int(0.6 * N), N)                               # 后 40% 作时间留出集
sg = lambda x: 1 / (1 + np.exp(-x))
lg = lambda p: np.log(np.clip(p, 1e-12, 1 - 1e-12) / (1 - np.clip(p, 1e-12, 1 - 1e-12)))

def auc(y, p):
    o = np.argsort(p, kind="stable")
    r = np.empty(len(p))
    r[o] = np.arange(1, len(p) + 1)
    return (r[y == 1].sum() - y.sum() * (y.sum() + 1) / 2) / (y.sum() * (len(y) - y.sum()))

def ece(y, p, bins=10):
    e = np.quantile(p, np.linspace(0, 1, bins + 1))
    i = np.digitize(p, e[1:-1])
    return sum((i == k).mean() * abs(p[i == k].mean() - y[i == k].mean())
               for k in range(bins) if (i == k).any())

pA, pB = sg(s), sg(1.4 * (s + 0.75 * g) + 0.6)            # 新模型：排序更好、概率更差
print(f"AUC {auc(y[te], pA[te]):.5f} -> {auc(y[te], pB[te]):.5f} "
      f"({100 * (auc(y[te], pB[te]) / auc(y[te], pA[te]) - 1):+.2f}%)")
print(f"ECE {ece(y[te], pA[te]):.4f} -> {ece(y[te], pB[te]):.4f}")
print("单调变换的 AUC 差",
      [f"{abs(auc(y[te], f(pB[te])) - auc(y[te], pB[te])):.1e}"
       for f in (lambda p: sg(1.2 * lg(p)), lambda p: p ** 0.8, lambda p: sg(1.6 * lg(p)))])
A, Z, ZB = 0.80, 1.959963984540054, 0.8416212335729143
Q1, Q2 = A / (2 - A), 2 * A ** 2 / (1 + A)               # Hanley-McNeil 的两个修正项
for nb in (1000, 10000, 100000):
    se = math.sqrt((A * (1 - A) + (nb - 1) * (Q1 - A ** 2) + (nb - 1) * (Q2 - A ** 2)) / (nb * nb))
    print(f"n={nb:>6d} SE={se:.6f} CI=±{Z * se:.4f} 可检出相对={100 * (Z + ZB) * se / A:.3f}%")
```

代码块 2（表 4：排序分 = 出价 × pCTR，赢家价 $b_2\hat p_2/\hat p_1$）：

```python
import numpy as np

rng = np.random.default_rng(20260928)
M, K, P = 50_000, 6, 2_000
bid = np.round(np.exp(rng.normal(np.log(0.75), 0.5, P)), 2)   # CPC 出价
qual = np.exp(rng.normal(0, 0.6, P))
newad = rng.random(P) < 0.25                                  # 25% 冷启动广告主
idx = (rng.random((M, K)) * P).astype(int)
for r in np.flatnonzero([len(set(row)) < K for row in idx]):
    idx[r] = rng.choice(P, K, replace=False)
ctx = np.exp(rng.normal(0, 0.5, (M, K)))
b = bid[idx]
p_true = np.clip(qual[idx] * ctx * 0.02, 1e-4, 0.3)
click = rng.random((M, K)) < p_true                           # 公共随机数：各变体共用同一批点击
noise = lambda s: np.exp(rng.normal(0, s, (M, K)) - s * s / 2)
lg = lambda p: np.log(np.clip(p, 1e-12, 1 - 1e-12) / (1 - np.clip(p, 1e-12, 1 - 1e-12)))
latent = qual[idx] * ctx * 0.02
pA, rank = latent * noise(0.45), latent * noise(0.22)         # 旧模型噪声大；新模型噪声小
mid = float(np.median(lg(rank)))
sg = lambda x: 1 / (1 + np.exp(-x))
shift = np.where(newad[idx], np.log(1.15), 0.0)
link = lambda p: sg(mid + 1.32 * (lg(p) - mid) + np.log(1.5) + shift)   # 过自信 + 全局上浮 + 桶偏置

def replay(p):
    s = b * p
    rows = np.arange(M)
    win = np.argmax(s, 1)
    sec = np.argmax(np.where(np.arange(K)[None, :] == win[:, None], -np.inf, s), 1)
    cpc = np.clip(b[rows, sec] * p[rows, sec] / p[rows, win], 0, b[rows, win])
    y1 = click[rows, win]
    return (cpc * y1).sum(), (b[rows, win] * y1).sum(), (win == np.argmax(b * p_true, 1)).mean()

for nm, p in [("A 旧（基线）", pA), ("B 新（题面）", link(rank)), ("B 排序+校准修好", rank),
              ("A+同套链路误差", link(pA))]:
    rev, val, acc = replay(p)
    print(f"{nm:16s} 收入={rev:8.1f} 价值={val:8.1f} 分配准确率={100 * acc:.2f}%")
print(f"纯全局缩放不变性：×0.9 前后收入差={replay(link(rank))[0] - replay(0.9 * link(rank))[0]:.3e} 美元")
```

## 常见追问

- **追问**：AUC 涨 2%，收入为什么不涨？
  - 要点：先把第 3 节的三条通道摆出来。AUC 只保证排序；收入由「计费价 × 成交额」决定，而二价计费价 $b_2\hat p_2/\hat p_1$ 对**相对**校准敏感（通道一）。表 4 里排序改善值 +11.48%、链路误差扣 −7.87%，净 −1.44%；再叠上预算约束（通道二）与转化延迟，1–2 周的窗口本来就检不出小损失。
- **追问**：为什么不能只看 AUC 当离线主指标？
  - 要点：AUC 对任何单调变换不变（本机三种变换的差都是 `0.0e+00`），也不惩罚系统性高估；决定计费的是概率值，不是名次。主指标要用价值加权的 log loss 与校准误差，并配 IPS/SNIPS 反事实收入与历史发布回测。
- **追问**：校准怎么修，isotonic 还是 Platt？
  - 要点：先分清用在哪条链路。计费链路推荐 Platt（参数少、不会破坏单调性、样本少也稳）；分桶阶梯大且样本足时才上 isotonic，而且必须加单调性检查与每段最小样本量；两种都只能在**近期时间留出集**上拟合（表 2：旧窗口 ECE 0.0787 vs 最近窗口 0.0411），排序链路一个字都不改。
- **追问**：怎么判断「收入持平」是真持平还是测不出来？
  - 要点：用真实样本量反算 MDE：$n=15.70\,CV^2/r^2$，CV = 3 时检出 0.5% 要 565 万用户/臂、1% 要 141 万。再依次查 SRM（$p<0.001$）、随机化单位的设计效应（$\rho=0.2$、$\bar m=4$ 时 MDE 乘 1.265）、连续窥视、转化成熟度与实验时长；都过关才敢说「无影响」。
- **追问**：怎么把「排序问题」和「校准问题」分开？
  - 要点：2×2 消融——保持排序分不变、只施加同一套链路误差（表 4 第四行 −7.87%），以及保持误差口径不变、只把排序换成新版（表 4 第三行 +11.48%）；再加一条影子流量：在零收入影响下用两版 pCTR 跑同一份流量，比较逐桶校准与计费口径。排序与校准是可分离的两个变量，分不开就没法定责。
- **追问**：这类损失多快能看见？
  - 要点：短期只看得见「分配准确率」和广告主级指标（ROAS/CPA、预算花完率、竞得率）；收入上的损失要等预算周期与竞争回归（竞价者会用脚投票），所以必须开 1% 长期 holdback 并事前注册判据，否则永远只能看到 1–2 周窗口里的噪声。
