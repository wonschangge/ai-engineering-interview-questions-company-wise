## 一句话答案

> 这类实验设计有一半的功夫在**动手之前**，顺序不能颠倒：
> ① **把「能力/偏见」操作化**：不能研究「涌现能力」这个抽象词，只能研究**某个具体任务上的可测量指标**（例如「3 位数加法准确率」、「反事实模板下指代选择的性别差异」）；
> ② **写出假设与判据**（预注册）：是「存在跃变」还是「连续提升但指标放大」？是「两组差异显著」还是「效应量超过某阈值」？**没写判据就会事后挑故事**；
> ③ **构造难度阶梯 + 反事实配对**：能力用**梯度难度的任务序列**（不是单一数据集）；偏见用**最小对立对（minimal pairs）**——只改受保护属性，其余全同；
> ④ **控污染 + 控混淆**：题目必须私有留出或持续更新（BIG-bench/LiveBench 式的做法），并排除「训练数据里见过该题」与「格式/分词差异」这类混淆；
> ⑤ **算样本量与统计功效**：要检出 5 个百分点的差异需要多少题？——用二项分布反算，**样本量不足的实验给出的「没差异」毫无信息量**；
> ⑥ **报告不确定性与多重比较**：置信区间、种子/温度方差、以及做多个对比时的校正；
> ⑦ **警惕「指标造成的人造涌现」**：可引用的关键结论是 *Are Emergent Abilities a Mirage?* ——许多「涌现」来自**非线性/不连续的指标**（如 exact-match 准确率）在底层能力连续提升时的放大效应；换成 token 级或连续指标，跃变常常消失。
> 一句话判据：**先在「指标层」证伪自己的结论，再谈模型层的能力**。

## 面试官在考什么

- **是否把抽象问题操作化**：「涌现能力」必须落成「某任务的某指标随规模/训练量的曲线」；「偏见」必须落成「配对样本上的差异度量」。
- **预注册与判据**：能否在实验前写下「什么结果支持、什么结果否定」，以及**效应的最小有意义值（SESOI）**。
- **统计功效**：给定效应量与样本量算出检出概率；反之由目标功效反算样本量。**这是本题最容易失分的地方**（多数人只讲「多看几条样本」）。
- **指标敏感性**：能否指出 exact-match 与 token-level accuracy 的区别，以及「指标不连续 ⇒ 人造涌现」这一机制（可引用口径：该论文给出「用连续指标衡量时涌现消失」的论证与实验）。
- **混淆控制**：格式、提示措辞、few-shot 数量、分词、长度分布、以及**污染**——每一项都可能制造或掩盖效应。
- **偏见的度量选择**：差异（disparity）用什么指标（配对准确率差、选择率差、几率比），以及**为什么必须用最小对立对**（否则差异可能来自名字频率等无关因素）。
- **可复现与可审计**：随机种子、提示模板、解码参数、评测脚本全部版本化；结果给出置信区间而不是单点。

**常见错误答案**

- 用公开榜单分数直接断言「涌现」——忽略污染与指标敏感性。
- 只跑 20–50 个样本就下结论（功效不足）。
- 偏见实验只换人名不换模板、不做配对（混淆无法排除）。
- 不做多重比较校正：测 20 个属性，总有几个「显著」。
- 只报均值不报方差/置信区间，也不报种子方差。

## 原理与推导

### 1. 步骤化流程（七步）

| 步骤 | 产出 | 常见错误 |
| --- | --- | --- |
| 1 操作化 | 指标定义（含边界情形） | 指标与结论不匹配 |
| 2 假设与判据 | 预注册文档 | 事后挑判据 |
| 3 任务/样本设计 | 难度阶梯 / 最小对立对 | 单一难度、单一模板 |
| 4 混淆控制 | 污染检查、格式对齐、few-shot 固定 | 格式差异被当成能力差异 |
| 5 功效分析 | 样本量 $n$ | 功效不足 |
| 6 执行与统计 | 均值、CI、检验、校正 | 只报点估计 |
| 7 稳健性与证伪 | 换指标/换模板/换种子 | 只做一次 |

### 2. 涌现能力：怎么设计才可能证伪

**任务阶梯**：把能力分解成单调难度序列，例如「多步算术」：1 步 → 2 步 → … → 6 步（每步都要同分布生成，避免难度跳跃由格式变化造成）。

**关键对照**：同一批模型输出，用**两种指标**分别评价：

| 指标 | 类型 | 特性 |
| --- | --- | --- |
| exact-match 准确率 | 不连续（全对才算对） | 底层能力连续提升时，指标呈 S 形/跃变 |
| token-level 准确率 / 编辑距离 | 连续 | 揭示底层能力的平滑提升 |

**结论判据（预注册）**：
- 若 exact-match 出现跃变而 token-level 平滑 → 支持「**指标造成的表象**」；
- 若两种指标都出现跃变 → 更可能是**能力层**的不连续（但仍需排除格式/污染）；
- 若跃变位置随提示格式漂移 → 支持「**评测设计造成的**」。

**这条判据可以直接做实验验证**（见代码第 ② 段：用同一组「底层能力连续提升」的模拟模型，比较两种指标给出的曲线形状）。

### 3. 偏见：最小对立对与效应量

**设计**：固定句子结构，只替换受保护属性：

```
[模板] "{name} 提交了报告，{pronoun} 的同事认为 {pronoun} 很..."
配对： (名字=典型男性名, 代词=他) vs (名字=典型女性名, 代词=她)
```

**度量**：
- 配对差异：$\Delta=\frac{1}{n}\sum_i \mathbb{1}[\hat y(x_i^{\text{group A}})\ne \hat y(x_i^{\text{group B}})]$（同一模板下两组输出不一致的比例）；
- 选择率差：$p_A-p_B$（例如「被推荐为领导者的比例」）；
- 几率比与置信区间。

**必须控制的混淆**：
| 混淆 | 例子 | 控制 |
| --- | --- | --- |
| 名称频率 | 某些名字更常见 | 从同频率池中选名 |
| 模板效应 | 模板本身有倾向 | 多模板 + 模板作为随机效应 |
| 语言/文化 | 英文名 vs 其他语言名 | 分语言分层报告 |
| 解码随机性 | 采样导致差异 | 固定种子 + 多次采样报告方差 |
| 多重比较 | 测很多属性 | Bonferroni/BH 校正 |

### 4. 统计功效：样本量怎么定

要检出两组差异 $\delta$（绝对百分点），用两比例检验的近似：

$$n\ \text{per group}\approx\frac{2\,(z_{1-\alpha/2}+z_{1-\beta})^2\,\bar p(1-\bar p)}{\delta^2}$$

$\alpha=0.05$、功效 80%、$\bar p=0.5$：$\delta=5\%$ → $n\approx1{,}570$；$\delta=10\%$ → $n\approx390$；$\delta=2\%$ → $n\approx9{,}800$。

**直觉**：要检出的差异越小，样本量按 $1/\delta^2$ 增长——**「差异 1 个百分点」的实验需要上万样本**，这是很多「偏见研究」结论不稳健的根源。

**偏见的配对设计更省样本**：因为同一模板内的配对比较消除了模板方差，等效于**配对检验**（同一样本量下功效更高）。

### 5. 污染与泄露控制

| 手段 | 说明 |
| --- | --- |
| 私有留出集 | 永不上网、永不进训练 |
| 持续更新基准 | 题目按月更新（LiveBench 式）；答案可自动判分 |
| 做题痕迹检测 | 检查模型是否能复述题目/答案（记忆探测） |
| 去污染记录 | 训练数据与评测集的重叠检测与记录 |
| 扰动测试 | 改数字/改名字后性能不应崩（崩了说明是记忆而非能力） |

### 6. 报告规范（可复现）

- 数据：题目、模板、种子、解码参数、模型版本（含日期）；
- 结果：每组的 $n$、点估计、95% CI、以及**多次种子的方差**；
- 分析：预注册的判据 + 事后探索**分开标注**；
- 局限：指标敏感性、污染可能、样本量功效、外部效度。

| 底层能力（连续提升） | exact-match 指标 | token-level 指标 |
| --- | --- | --- |
| 0.30 → 0.90 | 接近 0 后**突然**上升 | **平滑**上升 |

### 可运行代码

```python
# 1) 功效分析：给定差异与显著性水平，反算样本量
import math, random
from statistics import mean

def z(p):
    """标准正态分位数（近似，够用于功效估算）"""
    # Acklam 近似
    a = [-3.969683028665376e+01, 2.209460984245205e+02, -2.759285104469687e+02,
         1.383577518672690e+02, -3.066479806614716e+01, 2.506628277459239e+00]
    b = [-5.447609879822406e+01, 1.615858368580409e+02, -1.556989798598866e+02,
         6.680131188771972e+01, -1.328068155288572e+01]
    c = [-7.784894002430293e-03, -3.223964580411365e-01, -2.400758277161838e+00,
         -2.549732539343734e+00, 4.374664141464968e+00, 2.938163982698783e+00]
    d = [7.784695709041462e-03, 3.224671290700398e-01, 2.445134137142996e+00,
         3.754408661907416e+00]
    plow, phigh = 0.02425, 1 - 0.02425
    if p < plow:
        q = math.sqrt(-2 * math.log(p))
        return (((((c[0]*q+c[1])*q+c[2])*q+c[3])*q+c[4])*q+c[5]) / ((((d[0]*q+d[1])*q+d[2])*q+d[3])*q+1)
    if p > phigh:
        q = math.sqrt(-2 * math.log(1 - p))
        return -(((((c[0]*q+c[1])*q+c[2])*q+c[3])*q+c[4])*q+c[5]) / ((((d[0]*q+d[1])*q+d[2])*q+d[3])*q+1)
    q, r = p - 0.5, (p - 0.5) ** 2
    return (((((a[0]*r+a[1])*r+a[2])*r+a[3])*r+a[4])*r+a[5])*q / (((((b[0]*r+b[1])*r+b[2])*r+b[3])*r+b[4])*r+1)

def sample_size(delta, p_bar=0.5, alpha=0.05, power=0.8):
    z_a, z_b = z(1 - alpha / 2), z(power)
    return math.ceil(2 * (z_a + z_b) ** 2 * p_bar * (1 - p_bar) / delta ** 2)

print("① 样本量 vs 目标差异（α=0.05、功效 80%）")
for delta in (0.10, 0.05, 0.02, 0.01):
    print(f"  检出 {delta:.0%} 的差异：每组需要 {sample_size(delta):>7,d} 个样本")
print("  读法：样本量 ∝ 1/δ² —— 「1 个百分点」的结论需要近 4 万样本/组；")
print("        样本量不足时「没检出差异」不是证据")

# 2) 「人造涌现」：底层能力连续提升，但两种指标给出不同形状
def sim_models(n_models=12, n_items=2000, seed=3):
    """每个模型有一个连续的能力水平 a；单题正确概率 = a 经 sigmoid 后的值。
       exact-match 指标：整题全对（多步任务每步都要对）
       token-level 指标：按每步正确率累计"""
    rnd = random.Random(seed)
    rows = []
    for m in range(n_models):
        a = 0.30 + 0.60 * m / (n_models - 1)          # 底层能力从 0.30 连续升到 0.90
        steps = 4                                      # 4 步任务
        exact, token_ok, token_tot = 0, 0, 0
        for _ in range(n_items):
            all_ok = True
            for _ in range(steps):
                ok = rnd.random() < a
                token_tot += 1
                token_ok += 1 if ok else 0
                all_ok &= ok
            exact += 1 if all_ok else 0
        rows.append((a, exact / n_items, token_ok / token_tot))
    return rows

rows = sim_models()
print(f"\n② 同一批模型的两种指标（4 步任务、每步正确率 a）")
print(f"  {'底层能力 a':>10} {'exact-match':>12} {'token-level':>12}")
prev_exact = None
for a, ex, tok in rows:
    jump = "" if prev_exact is None else f"  (Δ={ex-prev_exact:+.3f})"
    print(f"  {a:>10.2f} {ex:>12.3f} {tok:>12.3f}{jump}")
    prev_exact = ex
print("  读法：底层能力 a 线性上升，token-level 指标平滑上升；")
print("        而 exact-match（要求 4 步全对 = a^4）在低能力区几乎恒为 0，随后「突然」抬升 ——")
print("        这正是「用不连续指标衡量连续能力会制造涌现有象」的机制（对照 Schaeffer et al.）")

# 3) 偏见的配对检验：最小对立对 + 置换检验（不依赖正态假设）
def paired_permutation_test(diffs, n_perm=10_000, seed=7):
    """diffs: 每个模板上的差异（A 组正确 - B 组正确，取值 -1/0/+1）"""
    rnd = random.Random(seed)
    obs = mean(diffs)
    cnt = 0
    for _ in range(n_perm):
        perm = [d * (1 if rnd.random() < 0.5 else -1) for d in diffs]   # 符号翻转
        if abs(mean(perm)) >= abs(obs):
            cnt += 1
    return obs, (cnt + 1) / (n_perm + 1)

rnd = random.Random(11)
true_effect = 0.08                                     # 真实存在的 8% 差异（两组各自的正确率偏移）
print("\n③ 偏见的配对置换检验：同样 8% 的真实效应，样本量不同结论不同")
print(f"  {'模板对数':>8} {'观测差异':>9} {'置换 p':>9} {'结论':>8}")
for n_templates in (60, 300, 600, 2000):
    diffs = []
    for _ in range(n_templates):
        a_ok = 1 if rnd.random() < 0.5 + true_effect / 2 else 0
        b_ok = 1 if rnd.random() < 0.5 - true_effect / 2 else 0
        diffs.append(a_ok - b_ok)
    obs, p_val = paired_permutation_test(diffs, seed=n_templates)
    print(f"  {n_templates:>8} {obs:>+9.3f} {p_val:>9.4f} "
          f"{'显著' if p_val < 0.05 else '不显著':>8}")
print("  读法：真实效应一样（8%），但 60 对与 300 对都拿不到显著性 —— 而观测差异还会因抽样噪声")
print("        偏离真值（本例 60 对时观测到 +0.13）。这就是「功效不足的偏见实验」的现场演示：")
print("        换一批模板就可能得到相反结论，所以配对设计之外**样本量同样必须算**")

# 4) 多重比较：测 20 个属性时至少一个假阳性的概率
def family_wise_error(n_tests, alpha=0.05):
    return 1 - (1 - alpha) ** n_tests
print(f"\n④ 多重比较（α=0.05）")
for k in (1, 5, 20, 100):
    print(f"  做 {k:>3} 个独立检验：至少一个假阳性的概率 = {family_wise_error(k):.1%}"
          f"（Bonferroni 校正后阈值 = {0.05/k:.4f}）")
print("  读法：测 20 个属性就有 64% 概率「至少一个显著」—— 不校正的偏见结论基本不可信")
```

预期输出要点（实跑）：① 功效分析给出「检出 10%/5%/2%/1% 差异」分别需要约 390 / 1,570 / 9,800 / 39,200 个样本每组，体现 $n\propto1/\delta^2$；② **人造涌现的机制被复现**：底层能力 $a$ 从 0.30 线性升到 0.90 时，token-level 指标平滑上升，而 exact-match（4 步全对，等价于 $a^4$）在低能力区长期贴地后突然抬升——**同一个模型序列、不同的指标给出「连续/跃变」两种结论**；③ 配对置换检验的样本量扫描给出一个**诚实的反面教材**：同样是 8% 的真实效应，**60 对（p=0.146）与 300 对（p=0.205）都不显著**，且观测差异被抽样噪声推来推去（+0.133 → +0.053），直到 **600 对才显著（p=0.0037）**、2000 对时 p=0.0001——**配对设计能提升功效，但不能替代样本量计算**；④ 多重比较显示做 20 个检验时**至少一个假阳性的概率高达 64%**，必须校正。

## 常见追问

- **追问**：怎么区分「真涌现」与「指标假象」？
  - 要点：换多种指标（连续与不连续）、换提示格式、换难度阶梯密度；若跃变随指标/格式移动，则是评测设计的产物。可引用的结论方向：*Are Emergent Abilities of LLMs a Mirage?* 指出许多被报告的涌现能力在改用连续指标后消失。
- **追问**：偏见实验为什么必须配对？
  - 要点：配对（最小对立对）让「除受保护属性外全部相同」，从而把模板/长度/领域方差消掉；非配对设计下的差异无法归因（可能只是名字频率或模板倾向）。
- **追问**：怎么防止「用自己的评测集调模型」造成的过拟合？
  - 要点：私有留出 + 定期轮换 + 只报告最终一次结果（不反复调参）+ 记录评测集访问历史；对公开榜单保持「参考信号」的定位（串 [[evaluation-06]]）。
- **追问**：样本量不够时怎么办？
  - 要点：① 降低目标（只宣称能检出大效应）；② 用配对/同方差设计提升功效；③ 报告置信区间（宽区间本身就说明证据弱）；④ 明确写「功效不足，结论为探索性」——**不要用「没显著」来宣称「无差异」**。
- **追问**：怎么报告更可信？
  - 要点：预注册 + 点估计与 CI + 种子方差 + 原始数据与脚本 + 事后分析显式标注；对负面结果同样报告（避免发表偏倚）。
- **追问**：如果是「能力是否随规模出现」的工业问题，实验怎么做才划算？
  - 要点：不追求一次定论，而是**用连续指标拟合外推曲线**（串 [[anthropic-21]]）+ 在关键规模点上做高功效的针对性评测；把「是否出现」改成「在什么规模、以什么指标、达到什么水平」这种可检验的命题。
