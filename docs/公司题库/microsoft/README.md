# Microsoft 面试题库

这一家的题有一个共同的前提：**功能要卖给一亿人**。
所以几乎每道题都会在某个时刻逼你回答**「这在规模上还成立吗」**——
3 秒的 p95 在 1 亿用户下还成立吗？成本在 1 亿 WAU 下是多少？权限在 1 亿用户的组织关系里怎么算？
一亿用户下「0.01% 的失败率」是什么概念？

准备这一家时，建议把**「规模换算」**当成习惯动作：
**任何百分比都要换算成绝对数，任何延迟都要换算成 p95，任何成本都要换算成单位经济**。
这一家的面试官明显更在意**「你的结论在规模上站得住吗」**，而不是「你知不知道某个技术」。

## 这家公司的面试怎么准备

**第一，把百分比换算成绝对数。** 这一家的题反复在考这个动作：
0.01% 的失败率 = **每天 1.5 万次坏摘要**；1% 的可访问比例 = **后过滤要取 1000 条候选**；
10 个群体 × 5 个指标 = **92.3% 概率出现假阳**。**说出绝对数，比说出百分比更有说服力。**

**第二，分清「能归零」与「不能归零」。** 这一家的安全题（08、09）都在考这个区分：
**未授权动作可以靠「去掉能力」归零**，**文本影响不能**；**模型偏差可以靠「配对设计」定位**，
**但「证明无偏」统计上不可行**。**能说清边界的人，比给一堆措施的人更专业。**

**第三，成本与延迟是同一枚硬币。** 03 与 04 是配套的：
**延迟余量就是成本**（利用率留余量 → 单位成本上升），**而权限隔离会削弱缓存这个最大杠杆**（45% → 30%）。
**面试时主动指出这些冲突**，比给一个「最优配置」更可信。

**第四，行为题要有量化。** 第 10 题用**成本结构**说明了「为什么验证前置几乎总是对的」——
**这一家的行为题同样期待你用数字支撑判断**（**盈亏平衡检出率 16.7% 这种数比「我学到了要更谨慎」强得多**）。
