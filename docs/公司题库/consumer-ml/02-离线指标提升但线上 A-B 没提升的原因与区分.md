## 一句话答案

> 先把题定性为**代理目标失配**，而不是离线指标不准：离线分 $S=\mathbb{E}_{\mathcal{D}_{bench}}[m]$、线上真实效用 $U=\mathbb{E}_{\mathcal{D}_{live}}[u]$，三处失配全部来自下标——分布不匹配、代理指标失败、优化过程只推高 $S$ 而不动 $U$（Goodhart 动力学）。裁决顺序固定：① 先看 null 的置信区间与事前 MDE，判断是真没提升还是这个实验本来就检不出；② 把整体拆成子集加权和 $\sum_g w_g U_g$，看是哪个桶在掉；③ 把线上失败样本回灌离线集，若离线分跟着掉就是分布与口径问题；④ 看 p95 延迟、成本、空召回率这类症候指标有没有先动（先动是工程回归，不是模型问题）；⑤ 全部排除后才怀疑离线主指标与业务目标的相关性。先怀疑统计与工程，再怀疑模型。

## 面试官在考什么

- **会不会先定性再归因**。上来就说「模型效果不行，回滚」的人漏掉了「线上没提升」里可能根本没有可检出的提升；能一句说出代理目标失配、并知道三处失配各自对应哪个诊断动作，才是这题要的粒度。
- **有没有子集加权和这个工具**。会不会把整体指标拆成 $\sum_g w_g U_g$，用真实流量占比重新加权，并意识到「整体不变」在子集空间里是一张等值面——子集之间可以互相抵消。
- **懂不懂离线集的 off-policy 本质**。日志来自旧策略的曝光分布，未曝光样本标签缺失且非随机；不记 propensity 的日志做不了反事实估计，也解释不了训练与评测数据被历史排序污染这件事。
- **统计纪律**。事前定 MDE 再反推样本量、随机化单位与指标粒度一致的假设、连续窥视的假阳率抬升、分流不均（SRM）、实验时长覆盖完整周期；把 $p>0.05$ 直接写成「无影响」是最常见的扣分点。
- **系统性归因的完整度**。四个版本轴（模型、特征与日志、索引、客户端与代码）、症状指标、护栏、双边市场的溢出与零和效应、长期 holdback，能不能一次列全并说清优先级。

常见的错误答案：

- 「离线指标不准」——把机制问题降级成情绪判断，既不给出失配的三个来源，也拿不出任何可执行的区分手段。
- 只答「分布不匹配」。漏掉检出力不足、子集被平均掉、上游召回瓶颈、工程回归、双边市场溢出、离线指标本身与业务目标不相关这几类；面试官只要追问「如果评测集就是按真实流量采的、也没泄漏呢」，这个答案就断了。

## 原理与推导

### 1. 形式化：三处失配全在下标上

消费级产品里的离线主指标通常是逐样本或逐列表的代理——AUC、NDCG@k、recall@k、RMSE、judge 偏好分；线上是业务效用——订单完成率、观看或收听时长、会话时长、留存或 DAU。两者连分母都不同，所以第一句该问的是：离线指标在哪个评测集、按哪个切分维度、用什么判据提升的。

$$S = \mathbb{E}_{x \sim \mathcal{D}_{bench}}\big[\, m(x, f_\theta(x)) \,\big], \qquad U = \mathbb{E}_{x \sim \mathcal{D}_{live}}\big[\, u(x, f_\theta(x)) \,\big]$$

三处失配全部来自这个式子的下标：$\mathcal{D}_{bench} \neq \mathcal{D}_{live}$（分布不匹配，第 2、3 节）、$m \neq u$（代理指标失败，第 9 节第 6 条的历史发布回测）、以及优化过程只推高 $S$ 不动 $U$（Goodhart 动力学，第 9 节）。第三类是纯动力学的：一旦 $S$ 成为目标，$S$ 方向上的可优化自由度里就混进大量与 $U$ 无关甚至反向的分量——只对评测集有效的后处理、格式、冗余特征、judge 偏好。

### 2. 子集加权和：平均分可以掩盖最痛的用户

$$U = \sum_g w_g U_g, \qquad \sum_g w_g = 1$$

$w_g$ 是线上真实流量在切分维度上的占比，$U_g$ 是子集效用。把它展开就能解释「大盘涨、体验差」：长尾子集（占真实流量 20%）从 60% 掉到 55%，其余 80% 从 75% 升到 78.75%，整体反而从 72% 升到 74%；把长尾占比换成 30%，整体又降到 71.6%——模型一行没改，只是流量构成变了（算例见「数值与代码验证」第 4 节）。

生产里必须分桶的维度：城市 × 时段（Uber 的供需与定价异质性）、片库 × 设备 × locale（Netflix）、语言与兴趣长尾（Pinterest）、新老用户 × 是否付费（LinkedIn、Airbnb 的冷启动与留存）、司机侧与乘客侧（双边市场要两侧各报）。只报总体分，等于把最痛的那部分用户平均掉，而且平均掉之后**没有任何指标会报警**。

### 3. 离线评测集是从旧策略日志里造的，本质是 off-policy

日志只覆盖旧模型愿意曝光、用户又看得见的东西。记 $\pi_{old}$ 为产出日志的策略、$\pi_{new}$ 为候选策略、$p_i = \Pr_{\pi_{old}}(a_i \mid x_i)$ 为倾向分，则

$$\hat{U}_{\mathrm{IPS}} = \frac{1}{n}\sum_i \frac{\pi_{new}(a_i\mid x_i)}{p_i}\,u_i, \qquad \hat{U}_{\mathrm{SNIPS}} = \frac{\sum_i w_i u_i}{\sum_i w_i},\quad w_i = \frac{\pi_{new}(a_i\mid x_i)}{p_i}$$

IPS 无偏但方差大（$p_i$ 小时权重爆炸），SNIPS 用权重和归一化，用一点偏差换方差。两者的前提都是日志里记了 propensity——不记，这批日志以后就永远做不了反事实评估。更隐蔽的是反馈回路：新模型上线后改变曝光，未来的训练与评测数据随之改变，评测集与线上分布的距离会自己随时间漂移。造集时还要逐项核对评测有没有用到线上拿不到的信息：未来信息泄漏（用到了决策时刻之后才产生的标签或特征）、比线上更全的候选池、更宽的时间窗、只有离线管道才有的特征——任何一项成立，离线增益都不可兑现。**所以「离线提升不可兑现」常常在造评测集那一刻就注定了，而不是在模型里。**

### 4. 位置偏差与反事实缺口

离线标签里没有「如果当初排序不同、用户会怎么做」这一项；未曝光样本的标签缺失且缺失非随机（用户只看得到前排）。于是离线涨的可能是**更好地拟合了旧策略的曝光分布**——学到了历史排序的位置先验，而不是内容相关性。恢复反事实只有两条路：

- 让线上日志自带随机性：小流量 epsilon 探索、按位置随机化曝光、propensity 落日志，之后才能用 IPS/SNIPS 把旧策略的选择偏差还原掉。
- 直接做 A/B：线上 A/B 是唯一直接观测反事实的量。

这正是「离线门禁、灰度、线上指标」必须串联的原因：离线门禁拦明显退化，灰度拦真实分布上的问题，线上指标兜住剩下的。探索流量的短期指标一定是负的，所以必须预算化——固定百分比、护栏、时长、事前写进实验登记单；把探索和全量发布混在同一个实验里，会同时污染收益估计和数据资产。

### 5. 两阶段链路：离线增益会被上游吃掉

线上链路是「候选生成 → 过滤（合规、库存、去重、去已看过）→ 重排」。重排的离线指标在全量候选上算，线上却只在过滤后的候选上生效：

$$\text{线上可兑现的排序增益} \;\lesssim\; \text{过滤后候选覆盖率} \times \Delta\mathrm{NDCG}_{\text{rerank}}$$

候选生成是瓶颈时，重排涨再多也只是在被召回的集合里做排列组合。判据是分段测：候选生成的 recall@K、过滤前后剩余候选数、过滤规则命中率、重排相对增益。生产坑：只看端到端离线分，不检查新模型是否让过滤规则在两组间变得不对称（新特征改变了去重或库存判定的命中率）。

### 6. 「真没有」还是「测不出来」

先看 null 的置信区间与事前 MDE。区间宽到 $\pm 2$pp、离线预测的增益只有 0.3pp 时，这个实验本来就不可能检出，此时任何「无效」的结论都不成立。把检出力拆成六项检查：

- **MDE 反推样本量**：$n = 15.70\,p(1-p)/\Delta^2$（二值）、$n = 15.70\,\sigma^2/\Delta^2$（连续），$\alpha = 0.05$ 双侧、power 80%。
- **随机化单位与指标粒度**：按用户或设备随机却按请求统计，有效样本量 $n_{\mathrm{eff}} = n / \big(1 + (\bar m - 1)\rho\big)$；$\bar m = 4$、$\rho = 0.2$ 时等效样本只剩 $n/1.6$，MDE 要乘 $\sqrt{1.6} \approx 1.26$。
- **方差缩减**：用实验前同期指标做协变量（CUPED 思路），相关系数 $\rho$ 时方差降到约 $1-\rho^2$，这是提检出力最便宜的手段。
- **不要边跑边看**：连续窥视把 5% 的名义假阳率抬到约 10%，「跑够显著为止」等价于挑一次赢的。
- **先查分流**：SRM 告警阈值取 $p < 0.001$ 而不是 0.05，因为它在每个实验里天天跑。
- **时长**：覆盖完整周期（$\ge 7$ 天，含周末），看稳态；新奇效应通常把前两天抬高。

### 7. 模型之外的回归：离线侧看不见的东西

四个版本轴——模型、特征与日志、索引与检索配置、客户端与代码——随请求写成结构化可检索字段，「效果变差」的第一问永远是「哪个版本变了」（[[evaluation-07]]）。离线评测通常完全不体现延迟与成本，而在这类产品里它们是体验一等公民：网约车的 ETA 与派单延迟、feed 的首屏时间、播放起播时间、搜索的无结果率。

症状指标比质量分更敏感，常先于投诉报警：p50/p95/p99 与服务分段延迟、首屏与起播时间、单位请求或 token 成本、空召回率与无结果率、fallback 与拒答率、输出长度。它们先动就是工程回归而不是模型问题。护栏（质量底线、延迟、成本、安全与多样性）破线一律停机，不因为主指标好看而放行。

### 8. 交互效应与零和的线上世界

双边市场与注意力共享平台里，实验组赚到的可能正是对照组亏掉的（司机与供给池、创作者曝光、社交反馈溢出）；相邻表面互相蚕食（首页涨、搜索跌，净效应为零）。这违背 A/B 的 SUTVA 假设，会让离线预测的增益在整体指标上被稀释甚至消失。手段：随机化单位选到与干扰范围匹配的粒度（市场或城市、用户，而不是请求），必要时用集群随机化或城市 × 时段 switchback，并显式监控溢出（跨组共享资源的暴露量、跨组用户比例）。

另外三类时间效应必须单独识别：新奇效应与首因效应（判据看稳态）、季节性与热点事件（流量构成漂移）、延迟反馈（订阅、留存、退款要等观察窗收敛）。生产坑：把需求侧的短期提升当成真实收益，忽略供给侧被挤压后的长期均衡——**两侧指标与长期 holdback（永久保留约 1% 对照流量）必须同时报**。

### 9. 把每条原因映射到可执行判据

1. **CI 宽到覆盖不了预期增益** → 判「检出力不足」：扩样本、改配对（同一批样本跑两侧，把样本难度从方差里去掉）、上 CUPED，而不是急着改模型。
2. **CI 明确排除预期增益、护栏正常** → 做三向交叉验证：换判据（人工盲评或换 judge 版本）、换分布（自建同源集 vs 离线集）、换时间（同版本隔周重跑估评测自身方差）；三者都过才把变化归因到能力。
3. **线上失败样本回灌后离线分跟着掉** → 分布与口径问题，先修评测集与加权重，而不是修模型。
4. **只在一个分桶里涨、其它桶掉** → 定位到路由、特征新鲜度或上游瓶颈（召回率、过滤规则、候选池）。
5. **症状指标先动** → 工程回归，按四个版本轴回滚或对齐配置。
6. **全部排除后仍不兑现** → 用历史发布做「离线 $\Delta$ × 线上 $\Delta$」的相关性回测，校准离线主指标与业务目标的关系；相关性低就换指标，而不是继续刷它。
7. **任何阈值都要有水位** → 同一版本 A/A 重跑（20–30 次），取 A/A 差值绝对值的 95 分位作为真差异下限；离线增量必须显著超过水位才算真提升，不知道水位时任何阈值都是拍的。

## 数值与代码验证

口径：二值指标每臂样本量 $n = 2(z_{1-\alpha/2}+z_{1-\beta})^2 p(1-p)/\Delta^2 = 15.70\,p(1-p)/\Delta^2$，连续指标 $n = 15.70\,\sigma^2/\Delta^2$；$\alpha = 0.05$ 双侧、power 80%，$z_{0.975} = 1.9600$、$z_{0.80} = 0.8416$，故 $2(1.9600+0.8416)^2 = 15.698$（与 [[evaluation-09]] 同一口径）。

### 1. 按 MDE 反推样本量（每组）

| 基线 $p$ | MDE 1pp | MDE 2pp |
| --- | --- | --- |
| 0.8（点击、观看完成） | 25,117 | 6,280 |
| 0.5（采纳、会话成功） | 39,245 | 9,812 |
| 0.1（无结果率、拒答率） | 14,128 | 3,532 |

连续指标（单位方差，$\Delta$ 以 $\sigma$ 为单位）：$0.02\sigma$ 要 39,245 条，$0.05\sigma$ 要 6,280 条，$0.1\sigma$ 要 1,570 条。

要检出 1pp 的体验差异、基线 0.8，每组要 2.51 万次会话；基线 0.5 时要 3.92 万次。表内一律向上取整，与 [[evaluation-09]] 表里的 39,244 / 6,279 / 1,570 差 1 以内，属于取整口径差异。

### 2. 设计效应、CUPED 与窥视

| 量 | 计算 | 结果 |
| --- | --- | --- |
| 设计效应（$\bar m = 4$、$\rho = 0.2$） | $1 + (\bar m - 1)\rho$ | 1.6（等效样本只剩 $n/1.6$） |
| 同上，MDE 放大 | $\sqrt{1.6}$ | 1.265（1pp 目标实际要按 1.27pp 设计） |
| CUPED 剩余方差（$\rho = 0.7$） | $1 - \rho^2$ | 0.51（等效样本接近翻倍） |
| 窥视假阳率（终点信息量口径，$K=1000$） | 40,000 次模拟 | 9.7%（反射原理渐近值 $4(1-\Phi(1.96)) = 10\%$） |
| 窥视假阳率（观测信息量口径，$K=1000$） | 每次用已收样本重算 SE | 53.0%（$K=10$ 时 19.3%，$K=100$ 时 37.4%） |

两种窥视口径必须分清：前者按计划终点信息量标准化（与 [[evaluation-09]] 的 9.6% 一致，40,000 次模拟的标准误约 0.15pp）；后者是平台每天用当时数据重算标准误的朴素做法，抬升随窥视次数无界增长。**无论哪一种，「跑够显著为止」都不成立，而且后一种会让假阳率失控。**

### 3. 分流不均（SRM）

总流量 1,000,000、计划 50/50 时，$\chi^2 = 4d^2/N$（$d$ 为单臂偏离 $N/2$ 的计数），1 自由度下 $p = \operatorname{erfc}\sqrt{\chi^2/2}$：

| 观测（对照 / 实验） | 失衡口径 | $\chi^2$ | $p$ |
| --- | --- | --- | --- |
| 501,645 / 498,355 | 单臂偏离 0.165pp（双臂差 0.33pp） | 10.82 | 0.0010 |
| 500,825 / 499,175 | 双臂差 0.165pp | 2.72 | 0.099 |

同一句「0.165pp 的失衡」在两套口径下结论相反（$p = 0.0010$ 对 $0.099$）：前者判 SRM，后者只是日粒度抖动。百万级流量下 SRM 告警阈值取 $p < 0.001$，因为它在每个实验里天天跑。

### 4. 子集加权算例

| 口径 | 长尾子集（占流量） | 其余子集 | 整体 |
| --- | --- | --- | --- |
| 基线 | 60%（20%） | 75%（80%） | 72.00% |
| 新模型 | 55%（20%） | 78.75%（80%） | **74.00%** |
| 新模型 + 长尾占比升到 30% | 55%（30%） | 78.75%（70%） | **71.62%** |

整体升 2pp 与最痛子集降 5pp 同时成立；只把流量构成换成 30%，同一份模型分数就把整体打到 71.6%。

### 5. 症状指标量级：把「多 2k 上下文」折算成延迟

用仓库统一常数（LLaMA-3-70B 每 token KV cache 320 KiB、8B 为 128 KiB、H100 bf16 dense 989 TFLOPs、带宽 3.35 TB/s、roofline 295 FLOPs/byte）：

| 量 | 计算 | 结果 |
| --- | --- | --- |
| 每请求多 2048 token 的 KV cache（70B / 8B） | $320\ \text{KiB} \times 2048$ / $128\ \text{KiB} \times 2048$ | 640 MiB / 256 MiB |
| 单序列 decode 每步多读这份 KV 的时间 | $640\ \text{MiB} / 3.35\ \text{TB/s}$ | 200 µs |
| 8k 上下文 KV（70B / 8B） | $320\ \text{KiB} \times 8192$ | 2.5 GiB / 1.0 GiB |
| 70B bf16 权重与 batch-1 decode 下限 | $140\ \text{GB} / 3.35\ \text{TB/s}$ | 41.8 ms/token（≈23.9 tok/s） |
| 算术强度 vs roofline | $2 \times 70\times10^9 / 140\times10^9$ vs $989/3.35$ | 1 vs 295 FLOPs/byte（带宽受限） |

排重、加特征、加摘要都会同时推高离线 NDCG 与这段延迟：200 µs/步在 30 步的生成里就是 6 ms，在 p99 上会被放大更多。**离线侧一个数都不报，线上却是体验的分子——这是「离线涨线上平」最便宜也最常见的来源。**

ZA, ZB = 1.959963984540054, 0.8416212335729143   # alpha=0.05 双侧、power=80%

print(round(de, 2), round(math.sqrt(de), 3), round(1 - 0.7 ** 2, 2))   # 设计效应 / MDE 倍数 / CUPED

def srm(a, b):                                                    # 两臂卡方，1 自由度
    n = a + b
    c = (a - n / 2) ** 2 / (n / 2) + (b - n / 2) ** 2 / (n / 2)
    return round(c, 2), round(math.erfc(math.sqrt(c / 2)), 6)
print(srm(501645, 498355), srm(500825, 499175))

def peek(K, trials=40000, seed=20260929):                         # 终点信息量口径
    rnd, sd, hit = random.Random(seed), 1 / math.sqrt(K), 0
    for _ in range(trials):
        z = 0.0
        for _k in range(K):
            z += rnd.gauss(0, sd)
            if abs(z) > 1.96: hit += 1; break
    return round(100 * hit / trials, 1)
print([peek(k) for k in (1, 10, 100, 1000)])

KIB, BW = 1024, 3.35e12                                           # 统一常数

      round(140e9 / BW * 1e3, 1), round(989e12 / BW, 1))

### 7. 红线指标的置信上界

护栏里的红线类指标（安全、合规）不能报点估计：$n$ 条全过时，用 rule of three 给上界约 $3/n$；300 条全过只能说违规率不高于约 1%（$3/300$），**不能说 0**。这条与「离线涨、线上不涨」的关系是：红线指标一旦用点估计，任何小样本的「零违规」都会变成放行依据。

## 常见追问

- **追问**：CI 宽到 $\pm 2$pp，而离线预测的增益只有 0.3pp，你怎么回？
  - 要点：先判检出力，而不是判模型。三个动作按代价排序：扩样本（或延长实验，前提是覆盖完整周期）；改配对——同一批用户或同一批候选跑两侧，把样本难度从方差里消掉；上 CUPED 用实验前同期指标做协变量（$\rho = 0.7$ 时方差降到 0.51，等效样本接近翻倍）。此外还可以缩短指标口径（用户级、会话级）来提信噪比。若预算内确实检不出 0.3pp，就明确写「该增益在当前样本量下不可测」，而不是写「无影响」。
- **追问**：怎么区分「评测集与线上脱节」和「模型真退化」？
  - 要点：从线上按真实流量分层采样一批真实会话（含失败样本），让新旧两个模型用**同一套判据**重跑。旧模型在这批新样本上也变好，说明是离线集脱节而不是模型变差；两侧判据不同源就会得到两个不可比的分数。配套机制是把线上失败样本持续回灌评测集，让 $\nabla S$ 带上 $\nabla U$ 的方向。
- **追问**：探索流量短期 KPI 一定是负的，怎么立项？
  - 要点：预算化：固定百分比（1%–5%）、护栏指标、明确时长、事前写进实验登记单，并把探索实验与全量发布拆成两个实验——混在一起会同时污染收益估计与数据资产。收益按「数据资产 + 反事实评估能力」立项，按护栏成本记账。
- **追问**：什么时候该怀疑上游瓶颈而不是排序模型？
  - 要点：只看端到端离线分时，先分段量：候选生成 recall@K、过滤前后剩余候选数、过滤规则命中率、重排相对增益。召回率是瓶颈时，重排涨的只是「在被召回集合内重新排列」的收益，线上天花板由候选覆盖率决定，先修候选生成再谈重排。
- **追问**：怎么知道离线主指标与业务目标相关？
  - 要点：用历史发布做「离线 $\Delta$ × 线上 $\Delta$」的相关性回测：横轴是每次发布在离线集上的提升，纵轴是同期线上主指标的提升，报相关系数与斜率。斜率接近零就说明这个代理指标测的东西与用户价值无关，换指标比继续刷它更值得。回测本身也要报样本量——发布次数通常只有几十次，相关系数的置信区间会很宽。
- **追问**：flaky 水位怎么定？
  - 要点：同一版本 A/A 重跑 20–30 次，取 A/A 差值绝对值的 95 分位作为真差异下限。评测只有几百条样本时，这个水位常在 1–3pp，比大多数真实改进都大——此时任何「离线提升 0.5pp」都是噪声。水位定下来之后，离线增量必须显著超过水位才算真提升。
