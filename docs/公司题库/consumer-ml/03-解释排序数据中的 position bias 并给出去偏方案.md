## 一句话答案

> 排序日志里的点击标签是 $P(\text{click}\mid \text{item 在第 } k \text{ 位}) = e_k \cdot r_{q,i}$ 的乘积：$e_k$ 是用户真的看到第 $k$ 位的概率（examination），随位次单调衰减，所以原始点击同时装着「相关」与「旧策略把它放在这里」两件事。去偏分两步：用一小片随机化流量估出可信的 $e_k$ 曲线，再让训练目标显式对这个 propensity 建模——IPS 加权、位置浅塔、点击模型、成对/列表损失择一，并配裁剪、平滑与分 segment 的 propensity。
> 训练侧去偏修不了从未曝光的候选（MNAR），必须与服务侧探索配额配对；评测也要换成随机化 holdout 或 interleaving，否则会把正确的改动判成退化。

## 面试官在考什么

- 能不能把 position bias 写成一个**可估计、可检验的量**（$e_k$ 曲线与它的估计口径），而不是一句「靠前的点击多」。
- 会不会把它与三类近邻偏差切开：曝光/选择偏差、位置—质量混杂、展示形态混杂；并且知道这三者里哪一个去偏根本修不了。
- 知不知道 $e_k$ 的唯一可信口径是随机化（同请求内打散 / 位置交换），以及它买到的无偏是用什么换的（该切片短期 CTR 与收入、有效样本量）。
- 能不能把 IPS 讲到「裁剪 + 有效样本量 + propensity 会过期」这一层，而不是只报一个方法名。
- 有没有把三件事串起来：训练侧去偏、服务侧探索、无偏评测尺子。缺任何一件，前一件的收益都留不住。

常见错误答案：

- 直接对位置做回归、或把位置当普通特征喂进模型，声称「把位置效应减掉」——位置与质量高度相关，这一步会把质量效应一起吸收，长尾被压得更低。
- 只背 IPS 公式：不裁剪、不报有效样本量、不考虑 propensity 随 ranker 版本漂移。上线后先看到长尾被过度抬高、再看到训练方差失控。

## 原理与推导

### 1. 把 position bias 定义成可估计的量

点击模型的基本分解（position-based model，PBM）：

$$P(\text{click}\mid q,i,k) = \underbrace{P(\text{examine}\mid k)}_{e_k} \cdot \underbrace{P(\text{click}\mid \text{examined}, q, i)}_{r_{q,i}}$$

$e_k$ 是 examination 概率，只依赖展示位次；$r_{q,i}$ 是 item 与查询的真实相关性（含价格、时长、库存满足度这些用户侧效用），与位次无关。这个假设本身就是可检验的：同一批候选用两套位次展示，若同一 item 的点击率随位次变化，就说明 $e_k$ 不为常数。

由此得到两条可落地的推论：

- **原始点击是 $e_k$ 与 $r$ 的乘积**，量纲上不可直接当相关性标签。未加权点式损失对位次 $k$ 的样本的期望梯度正比于 $e_k$，于是一个首位点击与一个第 10 位点击的权重比就是 $e_1/e_{10}$。
- **$e_k$ 随 $k$ 单调不增**是一条可校验的先验：首屏头部与第 10+ 位常差数倍。把这条约束加进估计（isotonic / PAVA）能显著压低深位置的估计噪声。

级联模型（cascade）是它的近邻：用户从上往下逐条判断，看到第一条满意结果就停止，于是「没被点击」可能只是没被看到。级联在单列结果页上比 PBM 更贴近现实，但多行网格、自动播放、无限流这些形态会直接破坏它的假设。

### 2. 四类近邻偏差要切开

- **① examination / position bias（本题主角）**：同一 item 换位置点击率就变。随机化流量测出的 $e_k$ 曲线是唯一可信口径，它对训练与评测都通用。
- **② 曝光 / 选择偏差**：只有上一版 ranker 的候选集进过日志，未曝光的 item 永远没有数据。这是 MNAR（missing not at random），**任何重加权都修不了**——它缺的不是权重，是样本。
- **③ 位置—质量混杂**：旧模型把高质量 item 排前面，位置与质量高度相关。直接把位置当特征、或对位置做回归，学到的是「旧模型觉得它好」而不是「用户觉得它好」。
- **④ 展示形态混杂**：摘要与缩略图、自动播放、行内位次（第几行第几个）与第几行是两套变量；不同 surface 的 $e_k$ 不同，必须显式建模。

### 3. 同名不同物：别把三种位置偏差混用

- 长上下文里的 U 形位置偏差（[[llm-internals-13]]）测的是「信息在 prompt 里的位置 → 模型利用率」，单位是准确率，机制是 attention 被摊薄与 RoPE 远距离失配。
- LLM judge 成对比较的位置偏好（[[evaluation-01]]）测的是「先出现者被选中的概率」，单位是胜率/一致率，机制是 prompt 里的顺序先验。
- 本题的 position bias 是「用户对展示位次的反应」，单位是点击概率，机制是 examination。

三者的纠正手段也不同：U 形靠 prompt 重排与位置扫描，judge 偏好靠交换取平均，排序偏差靠 propensity 与探索预算。答题时混用会显得只知道名词。

### 4. 不去偏为什么必然坏

**目标函数在复现 logging policy。** 训练样本的曝光与位次由上一版 ranker 决定，不加权拟合点击等价于最大化「历史排序下点击的似然」——模型学到的最强捷径就是「旧模型把它排前面」。迭代几轮后形成自证回路：长尾与新品永远拿不到曝光，模型越训越窄，新品冷启动越拖越长。

**离线尺子同时被污染。** 用点击标签算的 AUC / nDCG 会奖励「更贴合历史位置分布」的模型。复算示例：同一份合成日志上，只喂内容特征的模型留出 AUC 是 0.6310，多喂一个位置特征后升到 0.7926——16 个点的「提升」完全来自记录了 examination 强度，而 serving 时位置要等排序完才知道。**CTR 模型的 AUC 不能跨特征集、跨数据采集策略比较**，这正是同公司第 2 题「离线涨、线上不动」在排序场景的一个具体成因。归因时要把「训练数据偏差」与「指标代理偏差」分开报。

一个能当场报出来的口径：若 $e_1/e_{10} \approx 8$，未加权的点式损失等于给首位点击 8 倍权重；同一份日志里深位置的样本在「学相关性」，首位的样本在「学旧模型的排位」。

### 5. 一阶偏差的通用消除手段：交换与随机化

用最小 logistic 模型写清机制。设两个候选的真实质量差为 $s$（A 减 B），位置效应为一阶项 $\beta$：

$$p_1 = \sigma(\alpha s + \beta)\ (\text{A 在前}), \qquad p_2 = \sigma(\alpha s - \beta)\ (\text{A 在后})$$

把两次判定的概率相加记为 $g(\beta) = \sigma(\alpha s + \beta) + \sigma(\alpha s - \beta)$：$g$ 关于 $\beta$ 是偶函数，且 $g'(0) = \sigma'(\alpha s) - \sigma'(\alpha s) = 0$，所以 $\beta$ 的一次项恒为零，取平均后剩下的首项是 $O(\beta^2)$ 的偶次修正——交换消掉的是**一阶偏差**，不是全部偏差。$s = 0$（两个候选等价）时 $\sigma(\beta) + \sigma(-\beta) = 1$，平均精确等于 0.5000，与 $\beta$ 无关；$\beta = 1.0$ 时单次判定的「先出现者胜率」是 $\sigma(1) = 0.7311$，交换取平均后精确回到 0.5000。

代价是有效样本变小：$s=0$ 时两次判定同向才算「可判定」，其比例为 $2\sigma(\beta)\big(1-\sigma(\beta)\big)$，$\beta=1.0$ 时是 0.3932，其余 60.7% 记平局。

**这种「交换/随机化消一阶偏差」是通用手段，排序场景的对应物是把候选在展示位上随机化。** 位置效应能大到什么程度，MT-Bench 论文给了一组实测数字（**这是 LLM judge 成对比较的口径，不是排序场景实测值，这里只借量级**）：位置一致率 GPT-4 65.0%、GPT-3.5 46.2%、Claude-v1 23.8%；偏向第一个位置的比例分别是 30.0%、50.0%、75.0%；10 道数学题交换位置共 20 次判定，默认判错 14/20，给参考答案后降到 3/20。

线上落地方式是切 1%–5% 流量做位置随机化（[[evaluation-09]] 的 L2 小流量灰度口径）：同一次请求内把候选在展示位上均匀或 ε-greedy 打散，或做 A/B 交换。它有三个不可替代的作用——估 $e_k$、验证「位置只影响 examination」这个假设、给去偏后的 ranker 提供无偏评测集。它同时牺牲该切片短期的 CTR 与收入，所以只用它校准 propensity，不用它当主训练集。

### 6. propensity 的估计与维护

- **分层估计**：按 surface（feed / 搜索 / 推荐行）、端（移动 / 桌面 / 电视）、用户参与度、内容类型分层。深位置样本稀疏，必须加平滑与单调约束（$e_k$ 关于 $k$ 单调不增），否则尾部噪声会被放大成「长尾更优」的假结论。
- **落库字段**：每次曝光的位次、候选集、logging policy 版本、随机化种子、surface 与端。没有这些字段，训练集不可复算、不可回溯，事后无法判断某个涨点是去偏带来的还是数据漂移带来的。
- **propensity 本身会过期**：ranker 一换，$e_k$ 就变。要把「propensity 随 ranker 版本重建」做成流水线，并监控新旧 $e_k$ 曲线的漂移与校准（预测 CTR 与分桶实际 CTR 的偏差）。
- **小 segment 收缩**：分段之后每段样本骤减，用层级收缩把段内曲线拉向全局曲线（段内样本少时更靠近全局），否则分段本身会制造噪声。

### 7. 去偏方法菜单：给取舍，不给名词

1. **IPS / 逆倾向加权**：权重 $w_k = 1/e_k$，加权经验风险逼近无偏风险。必须裁剪（$e_k$ 下限 0.05–0.1 或权重上限）并报有效样本量。裁剪是偏差—方差旋钮：压住方差，但深位置样本仍带残余位置偏差。
2. **SNIPS 与 doubly robust**：自归一化（除以权重和）消掉一部分方差；DR 用一个人工/gold 相关性模型作 control variate。两者都要求先有一个不依赖位置标签的相关性估计，这是它们的入场费。
3. **点击模型（PBM / cascade + EM）**：直接从日志估 examination，不需要随机化流量，是最便宜的起步方案。可识别性依赖「位置只影响 examination、不影响 relevance」，在多行网格、多轮交互、自动播放的展示形态下不成立。
4. **位置浅塔**：训练时把位置放进 shallow tower，主塔只吃 query-item 特征；serving 时位置置常量（或按预测位次喂）。逼主塔学位置无关的相关性，代价是「首位适合放爆款」这类位置×内容交互学不到，且训练必须覆盖足够多的位次分布。
5. **pairwise / listwise 替代点式 CTR**：同一请求内按位置分层构造成对比较，尽量让对内的位置差小，或把位置差显式作为特征建模。它比较的是「同一位置上的相对优劣」，天然弱化全局 $e_k$ 的影响。
6. **位置随机化**：一阶偏差的通用消除手段，见第 5 节。它是校准器与评测集，不是主训练集。

### 8. 训练数据构造往往比损失函数更有效

把样本分成四档并分别加权，是排序场景回报最高的改动之一：

- **随机负例**：从全集里随机采的负例，代表「大概率不相关」。
- **曝光未点击**：既不是正例，也不是随机负例。它包含「看过但不满意」的信息；直接当负例会把「相关但价格高、时长长、位置远」的 item 教成不相关（[[system-design-04]] 的三档样本设计，Amazon Semantic Product Search 口径）。
- **点击**：弱正例。
- **强信号**：加购、播放完成、收藏、连接请求通过——这些行为的 examination 依赖远小于点击，是更接近相关性的标签。

配套两条纪律：采样负例时控制「同请求、同位置区间」的比例，避免负例分布本身被位置锁定；每条样本与 logging policy 版本、位次、估计的 $e_k$ 一起落库，训练集可复算。Amazon 那篇论文自报 Recall@100 至少 +4.7%、MAP +14.5%（与基线使用同一分词方法，且文中有线上 A/B 佐证），引用它的意义是「离线涨点必须配线上验证」，**不是本场景的预期收益**。

### 9. 评测：去偏后必须换一把无偏的尺子

- **随机化 holdout 或 interleaving**：把两个 ranker 的结果交错展示、比较点击偏好，对小流量改动比常规 A/B 更灵敏。[[rag-07]] 把它列为线上因果确认手段，并提醒点击是受位置偏差、曝光策略、摘要质量影响且滞后稀疏的弱信号，主判据应是无偏评测集。
- **人工分级的 gold 相关性小评测集**：排序层看 nDCG@10。BEIR 就是 18 个数据集、10 个系统、零样本跨域、以 nDCG@10 为主指标，BM25 是稳健强基线。
- **只用点击当金标会被污染**：BEIR 的 TREC-COVID 分析（论文 Table 4 口径）里，DPR 的 Hole@10 是 30.6%，补全标注后 nDCG@10 从 0.332 升到 0.445；ANCE 从 0.654 升到 0.735，于是「BM25 略胜 ANCE」变成「ANCE 胜 BM25」。标注的池化方式决定了结论。
- **功效先算再下结论**：二值指标每臂 $n = 15.70\,p(1-p)/\Delta^2$（[[evaluation-09]]，α=0.05、power 80%）。CTR 取 $p=0.05$ 时，检测 +10% 相对要每臂 29,830 次曝光，+5% 要 119,320；IPS 的有效样本量只有约 28.6%，同精度还要再放大约 3.5 倍曝光。
- **别在小样本上下结论**：$n=500$、$p \approx 0.8$ 时 95% 置信区间半宽约 3.5pp，$p=0.05$ 时约 1.9pp。500 条样本上的「离线 +2pp」是噪声，不能当去偏有效的证据。
- **排序指标比均值指标敏感**：[[rag-07]] 的合成集里单向量余弦的 0.005 扰动就对应 nDCG@10 掉 8.2 点、Top-10 换掉 24%。报排名指标要同时给置信区间与噪声底。

### 10. 这家公司场景的生产坑

1. **训练/服务 skew**：propensity 用旧 logging policy 的日志估，ranker 一更新即过期。把「随 ranker 版本重建 propensity」做成流水线并监控漂移，是这类系统的常规运维项。
2. **分段异质性**：$e_k$ 随 surface（feed / 搜索 / 推荐行）、端、用户参与度、内容类型变化。全局单一 $e_k$ 会系统性过校正或欠校正；要按 segment 估并对小 segment 做收缩。
3. **位置不止一维**：Netflix 的行内位次与第几行、Pinterest 的瀑布流、Spotify 的播放列表、LinkedIn 的 feed 与 PYMK、Uber Eats 的店铺列表，首屏 / 第几行 / 行内第几位 / 是否折叠或自动播放必须分开建模。同一用户在短窗口内的重复曝光要去重或降权，否则「已看过」会把 examination 估计带偏。
4. **冷启动与探索预算**：去偏只能修正已曝光 item 的偏差，修不了从未曝光候选的 MNAR。训练侧去偏必须与服务侧探索（新剧集、新用户、新供给的强制曝光配额）配对，否则回路依旧。
5. **护栏与回滚**：位置随机化短期压 CTR 与收入；IPS 加权会过度抬高长尾并把业务约束打乱（库存、地域、广告位、多样性）。A/B 随机化单位取用户或会话，避免同会话跨组（[[system-design-04]]）；护栏覆盖点击率 / 加购率 / 无结果率 / 退出率与 p99。
6. **别把「去掉位置偏差」当终点**：CTR 是弱标签，还要防「点了就走」。验收要落到长期留存与完成率，并与无偏评测集的方向一致。

读法有两条，缺一不可。第一条是**位置—质量混杂的量级**：平均位置在上半的 item，其 naive CTR 是 0.3834（真实 0.6162）；在下半的是 0.2172（真实 0.4793）。naive 把两组的差距放大成 1.77 倍，真实只有 1.29 倍——它制造了一个不存在的能力差。第二条是**无偏不等于可用**：IPS 把整体水平修对了（0.5461 对 0.5514，误差 1%），但在「曝光 ≥5 次」的样本上它的排序相关性反而低于 naive（0.5907 对 0.7105），因为深位置的小倾向把方差放大了；加上收缩（$m=10$）后 MAE 从 0.2530 降到 0.1522。生产结论是「无偏估计 + 收缩/平滑 + 无偏尺子」三件套，不是「打开 IPS 就赢」。覆盖率同样要报：20000 个 item 里 93.0% 有过曝光，只有 42.3% 曝光 ≥5 次，7.0% 从未曝光——这 1398 个 item 任何重加权都估不出来，只能靠探索预算。

随机化候选池上的 nDCG@10 印证同一件事：naive 排序 0.9757、裸 IPS 0.9607、IPS+收缩 0.9760，oracle 是 1.0000——裸 IPS 比 naive 还差，收缩之后才追平。naive 的排序相关性之所以不低，是因为这份合成日志里旧策略的排位本身就是质量的有噪声代理；一旦排位与质量解耦（推广位、陈旧模型、新品），naive 的这点优势就会消失。

核心可运行片段（完整脚本含合成日志实验）：

```python
import math
sig = lambda x: 1 / (1 + math.exp(-x))

# 1) 交换消一阶偏差：p1 = sig(a*s+b), p2 = sig(a*s-b)
for b in (0.5, 1.0, 1.5, 2.0):
    p1 = sig(b)                                  # s = 0 时先出现者胜率
    decisive = 2 * p1 * (1 - p1)                 # 两次判定同向才可判定
    print(f"beta={b}: p1={p1:.4f} 交换后={0.5:.4f} 可判定={decisive:.4f}")

# 2) e_k 几何衰减与 IPS 有效样本量
g = 8 ** (-1 / 9)                                # e_1/e_10 = 8
e = [g ** (k - 1) for k in range(1, 11)]
vif = sum(1 / x for x in e) / len(e)             # 曝光均匀、点击正比 e_k
print(f"e1/e10={e[0]/e[-1]:.3f} VIF={vif:.3f} ESS/n={1/vif:.4f}")

# 3) 二值指标样本量（α=0.05、power 80%）
for p, d in ((0.05, 0.005), (0.05, 0.0025), (0.8, 0.03)):
    print(f"p={p} delta={d}: n/arm={15.70*p*(1-p)/d**2:,.0f}")
```

## 常见追问

- **追问**：如果只有历史日志、没有任何随机化流量，能估出 $e_k$ 吗？
  - 要点：能估，但要多一层假设。PBM + EM 从日志里联立估 examination 与 relevance，靠的是「同一 item 在不同位次出现」与「位置只影响 examination」；级联模型还要加「逐条下滑」的结构假设。估计出来的是模型化结果，不是可直接信任的口径，必须用一小片随机化流量做校准；校准不了就退回到「只用 pairwise 的相对比较 + 强信号标签」，别直接用点击当绝对相关性。
- **追问**：为什么不干脆把位置当成一个普通特征，训练时用、serving 时置零？
  - 要点：这就是位置浅塔的简化版，方向对，但两个坑要主动说：一是位置与质量高度相关，位置特征的权重会把质量的一部分吸走，主塔学到的相关性被削弱；二是训练必须覆盖足够多的位次分布，否则浅塔在训练分布外的位次上外推不可靠。更稳的做法是位置进浅塔、主塔不吃位置，serving 时位置置常量。
- **追问**：IPS 加权后线上反而掉了，怎么排查？
  - 要点：先看有效样本量与权重分布（是不是少数深位置样本拿了极端权重）；再看 propensity 是否已过期（ranker 换版本后有没有重建）；再看裁剪点是否过松导致方差失控，或过紧导致长尾仍被压制；最后看业务约束是否被打乱（库存、地域、多样性、广告位）与护栏指标。顺序是先诊断权重、再诊断分布、最后诊断业务约束。
- **追问**：interleaving 和常规 A/B 什么时候用哪个？
  - 要点：interleaving 比较两个 ranker 的偏好，单位是「同一会话内的交错结果」，对小改动灵敏、样本需求小，但难接收入指标、也不适合带业务约束的组合；常规 A/B 用用户或会话随机、能接长期指标与护栏，但需要表 4 那个量级的曝光。常规组合是 interleaving 做早期筛选（快速淘汰明显更差的候选），A/B 做上线决策与护栏验证，主判据仍是无偏评测集。
- **追问**：去偏之后离线 nDCG 掉了，该不该上？
  - 要点：先确认掉的是哪把尺子。如果在点击标签算的旧指标上掉了、在随机化 holdout 或 gold 相关性集上没掉，那很可能是旧指标本身在奖励位置贴合，属于预期内；如果无偏尺子也掉，就要区分是去偏改动的代价还是 propensity 估计噪声。判断门槛用表 4 的功效口径，500 条样本上的 ±2pp 不构成证据。
- **追问**：新品和新用户怎么处理？
  - 要点：这是 MNAR 的部分，去偏修不了。做法是三条并行：训练侧对「无曝光历史」的 item 用内容侧特征与先验先打分；服务侧留强制探索配额（新品、新供给、新地域）并监控探索效率；评测侧对冷启动分层单独看指标，不要被头部流量的涨点盖住。
