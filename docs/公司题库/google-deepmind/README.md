# Google DeepMind 与 Google AI 面试题库

这一家的题有一个很清楚的骨架：**每道题都要求"先给结构，再给数字"**。
问 bias-variance，要写出分解式再跑实验；问 SVD，要说出 Eckart-Young 再算低秩近似的误差；
问 70B 训练，要先算 16 字节/参数的显存账；问 ETA 数据够不够，要先算分层后的每格样本数。

所以准备这一家时，建议把**"先解析、后数值"**当成习惯动作：
**任何结论都要能写成一个式子，并且能用一个可跑的实验验证它**。
这一家的面试官明显更在意**"你的推导能不能被检验"**，而不是"你记不记得结论"。

另一个特征是**大量题目都有"反直觉的正确答案"**：
抛硬币等 HH 是 6 次而不是 4 次；低秩分解在秩超过 nm/(n+m) 时反而更费参数；
同义词扩展**不会**提升全量召回；1000 题的基准只能检出 6.25pp 的差异。
**准备这一家，最该练的是"先算一下再说"。**

## 准备建议

1. **先做 05–12 这八道基础题**：它们是这一家的"数学底座"，而且**每一道都能用几十行 Python 验证**。练熟"先写解析式、再跑数值验证"这个动作。
2. **再做 13–14**：训练类题目的共同点是**都要先算账**（显存、通信、气泡）。把"16 字节/参数""气泡 $=(P-1)/(M+P-1)$""NVLink 900 vs IB 50 GB/s"记熟。
3. **15–18 是系统设计**：四道题的共同点是**都有一个"反直觉的量化结论"**（图像 token 比文本贵、召回率是天花板、反事实偏差、同义词不改全量召回）。**准备时把"拍脑袋"换成"算一下"**。
4. **19–21 是判断类题目**：它们的答案都是**"取决于约束"**——所以答题结构应当是**"先问约束清单，再给判据"**，而不是直接给结论。
5. **行为题只有一道，但要求量化**：把"期望值 vs 中位数""实验盈亏平衡"这两个工具准备好，**它们能把"沟通问题"变成"数字问题"**。
