# Scale AI 面试题库

这一家的题有一个统一的问法：**"你怎么知道这个数字/这份数据是可信的？"**
它不考模型结构，考的是**测量本身**。

**第一类问题是"没有 ground truth 时怎么度量"**。
主观偏好任务上没有正确答案，但可以测三件不需要答案的事：
**顺序互换的自我一致性**（好的标注者 90.3%、差的 63.5%）、
**位置偏置**（好的 −0.6%、差的 10.5%）、
**传递性违反率**（纯随机的基线是 **25%**——穷举 8 种组合里 2 种是循环）。
再加一件需要构造答案的：**注入"已知更差"的退化样本**。

**第二类问题是"检查器的精确率就是上限"**。
RLVR 的真实正确率**不超过检查器的精确率**（90% → 90%）；
RL 环境的奖励如果绑在 UI 文本上（错误率 **20%**），策略会收敛到伪造成功页；
agent 基准的错误信息如果泄露答案（30% 的任务），测得成功率**虚高 12 个点**。
**奖励与检查器的可信度决定了训练与评测的上限**——这是这一家最核心的工程直觉。

**第三类问题是"统计严谨性"**。
1,000 条题只能分辨 **4.38%**（要分辨 2% 需要约 4,800 条）；
公开集训练 5 轮后它涨 **20.3 个点**而私有集只涨 **4.5 个点**（差距 15.8 点就是过拟合）；
一个 6 分的下降要用 **2×2 分解**拆成"题目集 −3.0、配置 −2.0、交互 −1.0"。
**"先问这个数字能不能被相信"是这一家所有题的第一步。**

准备这一家时，建议把**"功效计算"**（要分辨 $\delta$ 需要多少样本）和**"混淆矩阵"**（精确率、召回率、误伤成本）练熟。
前者决定"要不要报警"，后者决定"要不要处理"。

## 准备建议

1. **先把"功效计算"练熟**：$n=(1.96\sqrt{2p(1-p)}/\delta)^2$。06 的"1,000 条分辨 4.38%"、07 的"64 题筛明显差的"、08 的"768 个任务"都是它的应用。
2. **01 与 07 是一对**：**01 是"有 ground truth"（用 Kappa）**、**07 是"没有 ground truth"（用自我一致性、位置偏置、传递性）**。两道连起来看就是完整的标注质量体系。
3. **03、04、08 是一条线**：**"检查器的精确率决定上限"**——03 讲理论、04 讲环境设计、08 讲基准设计。**这条线是这一家的核心工程直觉。**
4. **05 与 12 是"规模化运营"的两面**：一个做数据标注（250 FTE）、一个做机器人采集（审核 2.5 万小时）。**两者的共同发现是"真正的瓶颈在质量保证而不是生产"。**
5. **06 与 09 是"统计严谨"的两面**：一个讲"排行榜怎么保持可信"、一个讲"单次变化怎么归因"。**2×2 分解是 09 的核心动作。**
6. **10 不要当成"安全题"**：它其实是"质量体系能否发现'数据是假的'"，与 07 同源。
7. **11 的"界定"值得单独准备**：**"界定范围"的核心是"界定成功标准"**——这句话在这一家的题里反复出现。
