# Tesla 面试题库

这一家的题有一个统一的前提：**没有 lidar、算力与内存固定、数据来自自己的车队。**
第一个前提把"3D 感知"变成"深度估计问题"，
第二个把"模型设计"变成"Pareto 前沿上的取舍"，
第三个把"数据"变成"要自己造出来的东西"。

**第一件事是"几何决定上限"。**
摄像头没有直接深度，**深度误差与 $z^2$ 成正比**：**50 m 处一个像素的视差误差就是 5 m 的深度误差（10%）、150 m 处是 30%**；
而**0.1° 的外参误差在 50 m 处就是 8.7 cm**。
**所以"标定精度"和"时序累积"是无 lidar 方案的两条命脉。**

**第二件事是"极端不平衡下'调权重'是无效的"。**
$10^{-6}$ 的普遍率下，**FPR=1e-4 就对应 100 个假阳性、精确率上限只有 1%**——
**所以单级检测器无论多好都不够**；而**过采样到 1:1 等于把同一个样本重复一百万次**。
**有效的三条是"硬负样本挖掘 + 改目标 + 两级级联"，它们改变的是"问题"而不是"权重"。**

**第三件事是"数据引擎的瓶颈不在训练"。**
六阶段合计 18 天，而**标注（5 天）+ shadow 验证（4 天）占了一半，训练只有 3 天**；
**全传是 300 TB/天、按优先级只传 1% 是 3 TB/天**；
而**收益递减：第 1 轮 +2.5、第 8 轮 +0.27。**

准备这一家时，建议把**"$z^2$ 退化"**、**"精确率天花板"**、**"配对比较的方差削减"**这三条算术练熟。
它们分别解释了"感知能到什么程度"、"为什么单级不够"、"怎么比较两个版本"。

## 准备建议

1. **先把"$z^2$ 退化"背熟**：**50 m 处 1 像素 = 5 m、150 m 处 30%**（03）。**它是"无 lidar 方案能到什么程度"的答案**，也解释了为什么时序融合不可省。
2. **03 与 10 是一对**：**03 讲"只有摄像头时的极限"、10 讲"加上雷达与 IMU 后的结构"**。注意 IMU 的角色不是"第三路输入"而是"让其他传感器跨时间一致的条件输入"。
3. **04 与 05 是"数据的两端"**：**04 讲"正例太稀有"、05 讲"标注会强化盲区"**。两者的共同结论是"要靠模型之外的信号"。
4. **06 与 09 是"统计的两个用途"**：**06 检测分布偏移、09 比较两个版本**。而 09 的配对设计正是 06 里"控制混杂"的答案。
5. **07 的"动态范围被大目标占据"值得单独记**：它和 Apple 02 的"权重侧离群值"是同一个机制在两个张量上的表现。
6. **08 的"瓶颈不在训练"最反直觉**：**18 天里训练只占 3 天**。准备时要把"可并行的环节不是瓶颈"这条原则讲出来。
7. **01 的实测结论值得学**：**"预计算满矩阵"有交叉点、大 N 时反而更慢**。这说明"向量化"不等于"预先算所有对"。
8. **11 虽然是行为题，但它有可算的内核**：**"延迟决策的利息"**。把它当决策分析答会比当感想题答更有说服力。
