## 怎么用这些题解

这一组的每篇都包含四件可直接复用的东西：

1. **参考实现**：完整可运行（多数只用标准库与 numpy，部分用到 PyTorch），关键处有注释。
2. **可复现的实测输出**：文中「数值与代码验证」一节的数字都来自真实运行，审校阶段还做过「从文档抽取代码重跑」的复核。
3. **边界用例与断言**：例如 BPE 的 encode/decode 往返、SSE 的切分压力测试、LRU 的均摊复杂度、agent loop 的死循环防护。
4. **生产化差距**：每篇最后都会说明这段代码不能直接上线的原因，以及在真实系统里还需要什么。

## 自测清单

能不看资料写出下面这些东西，说明这个专题过关了：

- 手写带因果掩码的 attention，并说清掩码为什么必须在 softmax 之前。
- 把 MHA 改成 GQA 要改哪一处？KV cache 因此省下多少（给出算式）？
- 写出 KV cache 的单步 decode，并说明 RoPE 在什么时机施加。
- 写 BPE 训练，并解释编码时为什么必须按合并顺序而不是频次。
- 写 top-p 采样，并说清过滤后为什么必须重新归一化。
- 写 O(1) 的 LRU，并说清加 TTL 后「过期」与「淘汰」为什么是两套机制。
- 写 token bucket，并说明分布式化后时钟为什么不能取本地时间。
- 写异步批处理器，并解释 full jitter 解决的是什么问题。
- 写 SSE 解析器，并设计一个能证明「任意 chunk 边界」正确的测试。
- 写「不切开语义单元」的分块器，并说明找不到边界时的兜底策略。
- 写余弦检索，并解释为什么它不能上线（至少三条理由）。
- 写最小 agent loop，并说明失败时如何给出正常出口而不是崩溃或死循环。
