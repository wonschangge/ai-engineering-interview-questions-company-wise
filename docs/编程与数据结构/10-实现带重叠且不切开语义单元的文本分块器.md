## 一句话答案

> 「绝不切开语义单元」是约束，不是算法：先在结构层把文档切成标题 / 列表条目 / 代码围栏 / 表格，再在块内沿「句 → 子句 → 词 → 字符」逐级回退，每一层都只用完整的单元拼装；重叠同样只从前一块尾部回退完整的语句单元（token 数不超过预算），而不是按固定字符数回退——后者会把上一块的最后一句切掉一半，正好违反题目。代码围栏与表格是原子单元，宁可超限也不切开，单独成块并标 `oversize`。上限必须用真实 tokenizer 计量：实测同一份「1000 字符」预算，英文是 203 token、中文是 783 token。

## 面试官在考什么

- **是否把约束翻译成优先级链**：段落/标题 → 句子 → 子句（逗号分号）→ 词 → 字符，并说清每一级「找不到切点怎么办」。只会调 `RecursiveCharacterTextSplitter` 的候选人给不出这条链。
- **原子单元政策**：代码围栏与表格为什么宁可超限（半个表格没有列头、切开的代码丢掉签名与缩进语义），超限之后怎么办（单独成块 + 显式标记）。
- **句子边界检测的细节**：有没有真的处理 `e.g.` / `i.e.` 缩写、小数点、首字母缩写、中文标点、省略号、句末标点后的引号。`re.split(r'(?<=[.!?])\s+')` 会把一段正常文本切成 5 个碎片（第 4 节有实测）。
- **token 口径**：用真实 tokenizer 而不是字符数，因为跨语言不可比（[[coding-04]]、[[llm-internals-06]]）；且超过 embedding 模型 max length 的部分会被静默截断（[[rag-01]]）。
- **不变量测试**：能不能写出「区间合并还原原文」「原子块要么完整包含要么完全不包含」「块尾落在句末」「重叠是极大后缀且不超预算」这几条断言。

**常见错误答案**

- `text[i:i+500]`，再补一个 `text[i-50:i+500]` 当重叠：切在半个词/半个句子上，重叠也是字符级的，题目两条要求同时违反；而且 500 是字符还是 token 说不清。
- 只用 `re.split(r'(?<=[.!?])\s+', text)` 分句：`e.g.`、`3.5`、`等等……` 全被切开。
- 把 `len(text)` 当 token 数：同一份预算在中文上会超限 3 倍以上，超出部分在 embedding 侧被静默丢掉，块内容与向量对不上。

## 原理与推导

### 1. 契约：优先级链与兜底

| 级别 | 切点 | 何时使用 | 没有切点时 |
| --- | --- | --- | --- |
| 结构层 | 标题 / 围栏代码块 / 表格 / 列表条目 | 最先 | 纯文本无结构 → 直接进文本层 |
| 句 | `。！？…；` 与 `. ! ? ;` | 首选 | 单句超过上限 → 子句 |
| 子句 | `，,；;：:、` | 句子超限 | 无标点长串 → 词 |
| 词 | 空白 | 子句超限 | 单「词」超限 → 字符 |
| 字符 | 固定步长 | 最后兜底 | 必然能切，代价是破坏了语义，必须标记 |

超限只有三条出路，必须显式选一条：① 原子单元 → 单独成块并置 `oversize=True`，不改写内容；② 非原子但单个句子超限 → 逐级下钻，把实际用到的级别记在块上（级别 4 = 字符级，说明这块确实切开了句子）；③ 把超限块占比做成上游告警指标，而不是悄悄放行。

### 2. 结构层先切

标题层级、围栏代码块、表格、列表条目都是作者已标好的语义边界，先用它们（[[rag-01]] 的结构感知切分原则）。标题是硬边界，且标题路径要写进块首（`H1 > H2\n正文`）：块被单独取出后仍知道自己在讲什么，标题本身也是强检索词。代码围栏与表格是原子单元，只在原子块之间切；列表条目是单元，法律文档里一个条目就是一条义务。结构层的块区间要无缝覆盖全文（块间空白归前一块），这是「不丢字」能写成断言的前提。

### 3. 句子边界检测

一个位置算句末，要同时满足：标点属于句末类别；标点后允许跟收尾引号/括号；标点后是空白、文本末尾或非 ASCII 字符（中文标点后通常没有空格）；如果标点是单个句点，它前面的词不能是缩写表里的词（`e.g.`、`i.e.`、`etc.`、`Fig.`、`No.`），也不能是单字母（`J. Smith` 这类首字母缩写）。小数点与 URL 因为句点后紧跟非空白，天然被排除。

这是一张启发式规则表，不是语法解析器：它会把「参见第 8 条；」当成一句（中文分号按句末处理），也会在词表外的缩写（`Resp.`）上出错。工程上要让这张表可按语料配置并纳入回归测试——分句这类启发式一旦改动，影响的是一整条检索链路的指标。

### 4. token 预算必须用真实 tokenizer

字符与 token 的换算不是常数：实测英文技术文本 4.93 字符/token、中文 1.28、代码 3.05（口径 `tiktoken` 的 `o200k_base`，与 [[rag-01]] 一致）。于是同一份「1000 字符」预算在中文里是 783 token，在英文里只有 203 token；按字符定上限时，只要语料里中文占大头，块就会成片超过 embedding 模型的 max length，超出部分被静默截断，那部分文字永远不会进入向量。块上限应当定义为「max length − 标题路径前缀的 token 数」，本实现把前缀计入 `chunk.tokens`。

### 5. 重叠只从语义边界回退

规则：取前一块尾部「完整非原子单元」的极大后缀，其 token 数不超过 `overlap_budget = round(max_tokens × overlap_ratio)`。按固定字符数回退（`chunk[i-50:]`）会把上一块的最后一句切成两半，下一块开头就是半句话。拿不到重叠的四种情形与正常的空标记必须显式区分，而不是悄悄降级：

- `hard_boundary`：尾部是代码块 / 表格 / 标题——不切开原子单元。
- `unit_over_budget`：尾部单元本身就比预算大——宁可不重叠，也不切开它，也不让冗余系数失控。
- `no_room_for_overlap`：尾部单元的极大后缀装得进预算，但和下一块的第一个单元合起来会超过 `max_tokens`——宁可整段不重叠，也不挤掉新内容（这种情况下后缀仍会被丢弃，所以不能沿用 `unit_over_budget` 这个名字）。
- `whole_chunk`：前一块所有单元都落在预算内——丢掉首单元，保证下一块至少新增一个单元。
- 空字符串：正常重叠，是极大后缀且不超预算。

所以验证要打印共享 token 与豁免原因分布：豁免比例高，说明 `overlap_ratio` 相对「典型句长」偏小，这个参数该按句长定而不是拍百分比。

### 6. 拼装、不变量与复杂度

贪心装单元时用「单元 token 求和」估算，关闭每块时按真实计数核对，超限就把最后一个非原子单元退回下一块。三条不变量：① 每块 token ≤ 上限，除非它含原子单元（`oversize=True`）；② 后一块起点严格大于前一块（否则重叠会变成死循环）；③ 块区间按位置合并后能还原原文（重叠会让简单字符串拼接失败，必须按区间合并）。

复杂度：主要成本是 token 化，每个单元至少算一次；拼装只在关块阶段才做整块真实计数（超限就把最后一个非原子单元退回下一块再算一次），不做「每加一个单元就重新 token 化整块」，重复计数的是那些被退回的整块，量级仍是语料的常数倍，所以总 token 化量与语料 token 数同阶，整体 $O(N)$。常驻结构是单元表 + 当前块：`iter_chunks` 逐块产出，调用方不驻留历史块就能把峰值内存压到「单元表 + 1 块」，百万级文档因此可以按文档边界分片并行，也可以像 [[coding-09]] 那样流式消费而不是整篇读进内存。实测 0.39 M 字符语料：峰值内存 4.1 MB（全部块驻留）/ 2.8 MB（只消费当前块）/ 0.5 MB（1/10 语料）。

## 数值与代码验证

环境：python3 3.10 + `tiktoken` 的 `o200k_base`（未装 tiktoken 时退化为纯标准库估算），单线程，无 GPU（纯文本路径没有显存占用，用 `tracemalloc` 峰值内存代替）。脚本：`.work/chunker.py`（共 226 行，含下面的结构层状态机）、`.work/chunker_verify.py`（断言与基准）。样例文档含标题层级、围栏代码块、Markdown 表格、中英文混排、长短句、缩写 `e.g.`、小数点 `3.5`、中文省略号。下面的实现代码与样例输出逐字来自这两个脚本的运行结果。

**契约、token 计数与数据结构**（`chunker.py` 第 1~40 行）

```python
"""带重叠、且不切开语义单元的文本分块器（完整可运行的参考实现）。
契约：
1. 每块 = 标题路径前缀 + 原文切片，token 数 <= max_tokens；
2. 例外只有原子单元（围栏代码块 / Markdown 表格）：宁可超限也不切开，单独成块并标 oversize；
3. 重叠 = 前一块尾部「完整语义单元」的极大后缀，token 数 <= overlap_budget；尾部是原子单元、
   标题，尾部单元本身放不进预算，或该后缀与下一块首个单元合起来会超上限时不重叠，
   用 overlap_skipped 显式标记原因（hard_boundary / unit_over_budget / no_room_for_overlap / whole_chunk）；
4. 非豁免块的起止位置一定落在单元边界上（不会以半个句子结尾）。
"""
from __future__ import annotations
import re
from dataclasses import dataclass
try:                                                   # 真实 tokenizer；口径与仓库其它专题一致
    import tiktoken
    _ENC = tiktoken.get_encoding("o200k_base")
    def count_tokens(t: str) -> int:
        return len(_ENC.encode(t))
except Exception:                                      # 兜底：CJK 1 字符 ≈ 1 token，其余 4 字符 ≈ 1 token
    def count_tokens(t: str) -> int:
        cjk = sum(1 for c in t if "\u2e80" <= c <= "\u9fff")
        return cjk + (len(t) - cjk + 3) // 4
_FENCE = re.compile(r"^\s{0,3}(`{3,}|~{3,})")
_HEAD = re.compile(r"^(#{1,6})\s+(.*?)\s*\Z")   # 标题行
_ITEM = re.compile(r"^(\s*)(?:[-*+]|\d+[.)])\s+")
_END, _CLOSE = ".!?。！？…；;", "\"'”’」』)）]】"          # 句末标点 / 句末标点后允许出现的收尾符
_SEP = lambda s: "|" in s and "-" in s and not s.strip().strip("|-: \t")   # 表格分隔行
_ABBR = {"e.g", "i.e", "etc", "vs", "mr", "mrs", "ms", "dr", "prof", "inc", "ltd", "co", "fig", "no",
         "art", "sec", "u.s", "u.k", "approx", "cf", "al", "jr", "sr", "st", "dept", "est", "vol", "pp"}
@dataclass
class Unit:                                            # 结构块，或块内不可再分的语义单元
    kind: str; start: int; end: int                    # heading | paragraph | list_item | code | table
    level: int = 0                                     # 0 块边界 1 句 2 子句 3 词 4 字符
    heading: tuple = (); atomic: bool = False; tokens: int = 0
@dataclass
class Chunk:
    text: str; start: int; end: int; tokens: int; heading: tuple = (); prefix: str = ""
    oversize: bool = False; boundary: int = 0; overlap_skipped: str = ""; units: tuple = ()
    @property
    def render(self) -> str:                           # 真正送去 embedding / 入库的文本
        return self.prefix + self.text
```

**结构层：`parse_blocks`**（代码围栏 / 表格是原子块，标题是硬边界并更新标题路径）

```python
def parse_blocks(text: str) -> list[Unit]:
    """结构层切分：代码围栏（原子）/ 表格（原子）/ 标题 / 列表条目 / 段落。

    块区间无缝覆盖 [首块起点, len(text))：块间空白归前一块，标题路径随标题层级更新。
    """
    lines = text.splitlines(keepends=True)
    off, pos = [], 0
    for ln in lines:
        off.append(pos); pos += len(ln)
    area = lambda a, b: (off[a], off[b - 1] + len(lines[b - 1]))              # 行区间 -> 字符区间
    out, stack, i = [], [], 0
    while i < len(lines):
        ln, head = lines[i], tuple(t for _, t in stack)
        if not ln.strip():
            i += 1; continue
        if m := _FENCE.match(ln):                      # 代码围栏：原子；未闭合则吃到文件尾
            j = i + 1
            while j < len(lines):
                m2 = _FENCE.match(lines[j])
                if m2 and m2.group(1)[0] == m.group(1)[0] and len(m2.group(1)) >= len(m.group(1)):
                    break
                j += 1
            j = j + 1 if j < len(lines) else j
            out.append(Unit("code", *area(i, j), 0, head, True)); i = j; continue
        if m := _HEAD.match(ln):                       # 标题：硬边界，同时更新标题路径
            lv = len(m.group(1))
            stack = [x for x in stack if x[0] < lv] + [(lv, m.group(2))]
            out.append(Unit("heading", *area(i, i + 1), 0, tuple(t for _, t in stack))); i += 1; continue
        if "|" in ln and i + 1 < len(lines) and _SEP(lines[i + 1]):          # 表格：原子
            j = i + 1
            while j < len(lines) and lines[j].strip() and "|" in lines[j]:
                j += 1
            out.append(Unit("table", *area(i, j), 0, head, True)); i = j; continue
        if m := _ITEM.match(ln):                       # 列表：一个条目一个单元
            j, ind = i + 1, len(m.group(1))
            while j < len(lines) and lines[j].strip() and not _HEAD.match(lines[j]) \
                    and not _FENCE.match(lines[j]):
                j += 1
            st = [i] + [k for k in range(i + 1, j)
                        if (mm := _ITEM.match(lines[k])) and len(mm.group(1)) == ind]
            for a, b in zip(st, st[1:] + [j]):
                out.append(Unit("list_item", *area(a, b), 0, head))
            i = j; continue
        j = i + 1                                      # 段落：到空行或下一个结构行为止
        while j < len(lines) and lines[j].strip() and not _FENCE.match(lines[j]) \
                and not _HEAD.match(lines[j]) and not _ITEM.match(lines[j]) \
                and not ("|" in lines[j] and j + 1 < len(lines) and _SEP(lines[j + 1])):
            j += 1
        out.append(Unit("paragraph", *area(i, j), 0, head)); i = j
    for a, b in zip(out, out[1:]):
        a.end = b.start                                # 块尾吃掉块间空白，区间无缝
    if out:
        out[-1].end = len(text)
    return out
```

**文本层回退**

```python
def split_sentences(text: str, s: int = 0, e: int | None = None) -> list[tuple[int, int]]:
    """句子区间，覆盖 [s,e)；跳过 e.g./i.e. 这类缩写、小数点、首字母缩写与收尾引号。"""
    e = len(text) if e is None else e
    out: list[tuple[int, int]] = []
    def add(p: int, q: int) -> None:                   # 纯空白并进上一句
        if text[p:q].strip() or not out:
            out.append((p, q))
        else:
            out[-1] = (out[-1][0], q)
    start = i = s
    while i < e:
        if text[i] not in _END:
            i += 1; continue
        j = i
        while j < e and text[j] in _END:
            j += 1
        k = j
        while k < e and text[k] in _CLOSE:
            k += 1
        run, nxt = text[i:j], (text[k] if k < e else "")
        cut = any(c in "。！？；…" for c in run) or k == e or nxt.isspace() or (nxt and not nxt.isascii())
        if cut and run == ".":                         # 缩写与首字母缩写不是句末
            w = re.search(r"([A-Za-z][A-Za-z.]*)\Z", text[start:i])   # 取句点前的那个词
            t = (w.group(1) if w else "").lower().rstrip(".")
            cut = t not in _ABBR and len(t) != 1       # 前一个词不是字母（如 Section 8.）仍算句末
        if cut:
            add(start, k); start = i = k
        else:
            i = k
    if start < e:
        add(start, e)
    return out
def split_to_budget(text: str, s: int, e: int, budget: int, level: int = 1) -> list[tuple[int, int, int]]:
    """递归回退：句 -> 子句（逗号/分号/冒号/顿号）-> 词 -> 字符。
    返回 (start, end, 边界级别)。级别 4 是唯一会切开句子的路径，会被显式标记出来。
    """
    if level == 1:
        parts = split_sentences(text, s, e)
    elif level == 2:
        parts, p, i = [], s, s
        while i < e:
            if text[i] in "，,；;：:、":
                j = i + 1
                while j < e and text[j] in "，,；;：:、":
                    j += 1
                parts.append((p, j)); p = i = j
            else:
                i += 1
        if p < e:
            parts.append((p, e))
    elif level == 3:
        parts = [(s + m.start(), s + m.end()) for m in re.finditer(r"\S+\s*", text[s:e])]
        if parts and parts[-1][1] < e:                 # 尾随空白并进最后一个单元
            parts[-1] = (parts[-1][0], e)
    else:                                              # 字符级兜底：按预算估算步长后硬切
        step = max(1, (e - s) * budget // max(1, count_tokens(text[s:e])))
        out, p = [], s
        while p < e:
            q = min(e, p + step)
            while q > p + 1 and count_tokens(text[p:q]) > budget:
                q = p + (q - p) // 2
            out.append((p, q, 4)); p = q
        return out
    if len(parts) <= 1:                                # 这一层没有切点
        if count_tokens(text[s:e]) <= budget:
            return [(s, e, level)]                     # 整段就是一个单元
        return split_to_budget(text, s, e, budget, level + 1)
    out: list[tuple[int, int, int]] = []
    for ps, pe in parts:
        out.extend(split_to_budget(text, ps, pe, budget, level + 1)    # 单个片段仍超限：下钻一层
                   if count_tokens(text[ps:pe]) > budget else [(ps, pe, level)])
    return out
```

**单元表、拼装与重叠**

```python
def prefix_of(u: Unit) -> str:
    """入库文本的标题路径前缀；块首本身就是标题时只回填祖先层级，避免与正文重复。"""
    p = u.heading[:-1] if u.kind == "heading" else u.heading
    return " > ".join(p) + "\n" if p else ""
def build_units(text: str, max_tokens: int):
    """结构层 -> 单元层：代码 / 表格 / 标题各成一个单元，正文永远下探到句子粒度。"""
    for b in parse_blocks(text):
        if b.atomic or b.kind == "heading":
            b.tokens = count_tokens(text[b.start:b.end])
            yield b
        else:
            for s, e, lv in split_to_budget(text, b.start, b.end, max_tokens):
                yield Unit(b.kind, s, e, lv, b.heading, False, count_tokens(text[s:e]))
def iter_chunks(text: str, max_tokens: int = 512, overlap_ratio: float = 0.15,
                overlap_budget: int | None = None):
    """产出块序列；调用方不驻留历史块时，常驻内存只有当前块与单元表。"""
    units = list(build_units(text, max_tokens))
    budget = overlap_budget if overlap_budget is not None else max(1, round(max_tokens * overlap_ratio))
    n = len(units)
    exact = lambda a, b: count_tokens(prefix_of(units[a]) + text[units[a].start:units[b - 1].end])
    lo, skip = 0, ""
    while lo < n:
        hi = lo + 1                                    # 贪心装单元：标题是硬边界
        while hi < n and not (units[hi].kind == "heading"
                              and any(u.kind != "heading" for u in units[lo:hi])) \
                and sum(u.tokens for u in units[lo:hi]) + units[hi].tokens <= max_tokens:
            hi += 1
        while hi - lo > 1 and not units[hi - 1].atomic and exact(lo, hi) > max_tokens:
            hi -= 1                                    # 按真实计数收缩：回退整个单元
        us, pre = tuple(units[lo:hi]), prefix_of(units[lo])
        body = text[us[0].start:us[-1].end]
        tok = count_tokens(pre + body)
        yield Chunk(body, us[0].start, us[-1].end, tok, us[0].heading, pre, tok > max_tokens,
                    max(u.level for u in us), skip, us)
        if hi >= n:                                    # 没有未消费的单元了
            return
        acc, j = 0, hi                                 # 重叠：尾部完整非原子单元的极大后缀
        while j > lo:
            x = units[j - 1]
            if x.atomic or x.kind == "heading" or acc + x.tokens > budget:
                break
            acc += x.tokens; j -= 1
        tail_over_budget = j >= hi                     # 尾部单元自己就放不进预算
        while j < hi and sum(x.tokens for x in units[j:hi]) + units[hi].tokens > max_tokens:
            j += 1                                     # 重叠挤掉新内容：从最老的单元起丢
        if j <= lo:
            j, skip = lo + 1, "whole_chunk"            # 整块都落在预算内：保证前进
        elif j >= hi:
            j = hi
            skip = "hard_boundary" if (units[hi - 1].atomic or units[hi - 1].kind == "heading") \
                else ("unit_over_budget" if tail_over_budget else "no_room_for_overlap")
        else:
            skip = ""
        lo = j
def chunk_document(text: str, max_tokens: int = 512, overlap_ratio: float = 0.15,
                   overlap_budget: int | None = None) -> list[Chunk]:
    """一次性拿到全部块（验证与基准用）；生产管线用 iter_chunks 逐块消费。"""
    return list(iter_chunks(text, max_tokens, overlap_ratio, overlap_budget))
```

## 常见追问

- **追问**：为什么不能按固定字符数切，overlap 也不能按字符回退？
  - 要点：切点由计数而非语义决定，会落在词和句子中间；字符与 token 不是常数换算（中英差 3.9 倍），同一套常数跨语言不是同一个粒度；按字符回退重叠会把上一块的最后一句切掉一半，下一块开头就是半句话，直接违反题目约束。正确做法是回退完整的语句单元，取尾部单元的极大后缀并用 token 预算设上界。
- **追问**：重叠要不要包含元数据（标题路径）？
  - 要点：标题路径每个块都要有，但它是按当前块的位置重新生成的（`prefix_of`），不是从上一块复制来的重叠；它同样计入 token 预算。标题路径还要以结构化字段（`heading_path`）另存一份用于过滤与加权（[[rag-01]]）。每块元数据至少要有：doc_id、标题路径、字符区间 `[start, end)`、token 数，以及 `oversize` / `boundary` / `overlap_skipped` 三个质量标记——字符区间是高亮引用与「论断归因到 span」的前提（[[rag-12]]）。
- **追问**：一句话超过 chunk 上限怎么办？
  - 要点：按优先级下钻——子句 → 词 → 字符，每块记录实际用到级别，级别 ≥ 2 的块入库时打标并统计占比；仍超限就接受并标 `oversize`（不要假装没发生）。如果这种块占比很高，说明 chunk 上限相对语料句长偏小，该调参数而不是继续下钻。
- **追问**：代码块或表格比上限还长怎么办？
  - 要点：原子块单独成块 + `oversize` 标记，不切开。生产上再给大单元专用路径：超长表格按行组切分时重复表头，超长代码块按顶层函数/类切分，复杂版面改走页面图像检索（[[rag-10]]、[[multimodal-10]]）。本实现故意不做，把决策留给下游——怎么切取决于语料语义，通用分块器不该替业务决定。
- **追问**：重叠比例调大是不是更安全？
  - 要点：不是。重叠是存储与 prompt 的双重冗余，冗余系数约 $1/(1-o/C)$：实测 `o/C=0.15` 时 1.157、`0.30` 时 1.420（理论 1.429）；更贵的是检索侧——相邻块同时命中时重复文本一起进 prompt，白占预算还可能让模型读两遍同一句话（[[rag-03]]）。而预算太小时重叠是假的：实测 `o/C=0.05` 时 83% 的相邻块没有共享内容。先按「典型句长的 2~3 倍」定预算，再用检索指标验证。
- **追问**：怎么证明分块策略真的改好了？
  - 要点：端到端闭环——固定 embedding 模型、索引参数与生成器，只变分块器，在同一份带标注答案 span 的问题集上比 recall@k / nDCG@k 与答案正确率，并按答案跨度分层看（[[rag-04]]、[[evaluation-04]]）。反直觉但常见：块更小、重叠更多不一定提升端到端指标——上下文变碎、噪声变多，生成器反而更容易漏掉前提；端到端持平甚至变好时也要看检索指标与 prompt token 数，别用更贵的上下文换一个持平的分数。改分块必须全量重建索引，否则库里是两套粒度混在一起。
