## 一句话答案

> ASR 侧：WER 是「最小编辑距离 ÷ 参考词数」，它把专有名词和虚词等权、结论随归一化口径漂移、在 code-switching 与多语言下定义不清，单数据集上的数字也不代表泛化。所以要换成一组指标：**分群 WER**（口音、噪声、远场、语速、年龄、术语）+ **实体与格式准确率**（数字、金额、姓名、代码标识符）+ **语义与下游任务成功率** + **流式指标**（首字延迟、部分结果翻转率、句尾延迟）+ **置信度-拒识曲线**；每个数字都带归一化口径版本、样本量和置信区间。
> TTS 侧：输出不唯一使编辑距离失效，质量本身是多维的（可懂度、自然度、韵律、音色相似度、稳定性），正确做法是**小规模人工受控主观评测做校准 + 大规模自动代理指标做回归 + 下游任务指标做仲裁 + 分群报告**；MOS 必须配样本量与置信区间，能成对比较就不要绝对打分，任何自动指标上线前先证明它与人工判断相关。

## 面试官在考什么

- **能不能把「WER 不够用」讲成机制**：不是背四个缺点，而是说清每一项为什么会在生产里造成错误决策（等权 → 优化了不重要的错误；口径 → 跨季度数字不可比；code-switching → 指标定义决定结论；单数据集 → 泛化幻觉）。
- **有没有分层指标体系**：口音/噪声/信道分群、实体与格式、语义与下游、流式、置信度拒识——这五层分别对应「谁受影响」「错在哪」「任务成败」「交互体验」「能否兜底」。
- **懂不懂主观评测的统计性质**：MOS 的方差来源、样本量与置信区间的换算、成对比较（CMOS / ABX / MUSHRA 类）为什么比绝对打分稳、多重比较怎么处理。
- **会不会区分目标指标与代理指标**：TTS 的自动指标全是代理（说话人相似度、ASR 反测 WER、F0 分布、神经质量打分），每一项都有明确失效模式，必须先在留出集上验证与人工判断的相关性。
- **有没有发布纪律**：口径版本化、评测集不回流训练、分群报告、人工校准与自动回归的分工。

常见错误答案：

- 「MOS 就是多找几个人打分取平均」——不给听者群体与协议、不给样本量与置信区间、把不同实验的 MOS 放在一张表里比大小。
- 「用 ASR 反测合成语音的 WER 就是可懂度」——带语言模型的 ASR 会用先验把发音错误改回正确词，指标偏乐观，而且对韵律、重音、情绪完全不敏感。

## 原理与推导

### 1. WER 的定义，以及它的四个缺陷

参考转写 $R$、系统假设 $H$，按最小编辑距离对齐后

$$\text{WER} = \frac{S + D + I}{N} = \frac{\mathrm{Lev}(R, H)}{|R|}$$

其中 $N = |R|$ 是参考词数，$S/D/I$ 分别是替换、删除、插入数（因此 WER 可以超过 100%）。四个缺陷：

**① 等权：所有词错误代价都是 1。** 下游在意的是实体（店名、金额、日期、药名、账号、代码标识符），而 WER 把 `the → a` 和 `ritz → writs` 记成同样的 1 个错误。数值节给出的一对例子：一处是实体错、一处是句尾多一个 `please`，WER 都是 9.09%，但一个任务必败、一个毫发无损。**单看 WER 无法把「信息错误」与「冗余差异」分开**，必须并列报 $S/D/I$ 分解与实体级准确率。

**② 依赖归一化口径。** 标点、大小写、数字与货币形态（ITN）、填充词（um / uh）、英式美式拼写、是否做 transliteration，任何一项都会改变分母与编辑距离；聚合口径（语料级 micro 还是逐句 macro）与分词口径（中文、日文没有稳定词边界，通常改用字错误率 $\text{CER} = (S+D+I)/N_{\text{字}}$）同样会改变数字。数值节复算的同一对参考/假设，在三种口径下是 55.6% → 25.0% → 0.0%。结论：**每个 WER 数字必须携带（归一化版本、分词器版本、聚合方式）三元组**，否则跨版本、跨团队、跨季度都不可比。

**③ code-switching 与多语言下定义不清。** 一句「这个 deadline 是下周三」里，英文词用拉丁字母还是当地文字书写、外来词按音译还是按原词对齐，会直接改变 WER 的量级。一项针对 code-switching ASR 指标的研究（SLT 2022）正是冲着这个问题：它构造了带人工判断的 code-switching ASR 假设参考基准，用 4 方标注一致性校验「最小编辑」指南，然后横向比较在**表示（正字 / 音系 / 语义）、直接性（内在 / 外在）、粒度（词 / 字）、相似度算法**上各不相同的大量指标与人类判断的相关性，结论是**先做转写（transliteration）再做文本归一化的指标与人类判断相关性最高**。这条结论的价值不在于选出某个指标，而在于说明：**指标定义本身就能改变结论**——多语言产品的评测必须固定脚本与转写规则，并单独报语种切换点附近的错误率。

**④ 单数据集上的 WER 会误导。** *Rethinking Evaluation in ASR* 的口径是：在单个数据集上继续推数字价值有限；当使用足够大的一组 benchmark 时，其**平均 WER** 才是真实噪声数据上表现的良好代理；混响与加性噪声增强能提升跨域泛化；而把最常用的若干数据集合并训练，单个声学模型也能在研究集与真实集上同时取得有竞争力的结果。工程含义：评测集必须包含训练域之外、带真实信道与噪声的集合，并报多集合平均而不是挑最好看的那一个。

### 2. ASR 要补的五组维度

**① 分群鲁棒性。** 按口音 / 母语、SNR 与噪声类型、远场 vs 近讲、语速、说话人年龄（儿童 / 老人）、领域术语把评测集切片，每组报「WER + 样本量 + 置信区间」，并给一个汇总量——最差组与最好组之比（worst-group gap，必要时并列最差组 ÷ 总体）。数值节的例子：总体 5.2% 是 3.0% 与 14.0% 两个群的混合，最差组与最好组之比 14.0/3.0 = 4.67 倍（最差组相对总体是 14.0/5.2 = 2.69 倍）；再按线上流量（弱势群占 40%）重加权，预期 WER 是 7.4%。**不报分群与流量分布的总体 WER，其数值由评测集混合比例决定**，这是最容易被 A/B 结果反噬的地方，也是群体差异审计在语音上的对应物（[[safety-09]]）。

**② 实体与格式准确性。** 预先定义实体集 $E$（人名、地名、数字、日期、金额、账号、药品名、代码标识符），用结构化比较而不是字符串比较（`twenty three` ≡ `23` ≡ `23 元`），报

$$\text{EntityAcc} = \frac{1}{|E|}\sum_{e \in E} \mathbb{1}[\hat e = e], \qquad \text{NEER} = 1 - \text{EntityAcc}$$

必要时再用一个业务加权的中间口径：给参考 token 赋权 $w_j$（实体 3、内容词 1、虚词 0.2 之类的量级，具体权重必须由业务价值标定并写进配置），插入错误按插入位置的相邻参考 token 取权。

$$\text{WER}_w = \frac{\sum_{j \in R} w_j \cdot \mathrm{err}_j}{\sum_{j \in R} w_j}$$

这是自定义口径而非论文指标，跨团队不可比，但它在「只想要一个数」的场合比裸 WER 更贴近业务。

**③ 语义与下游指标。** 句向量余弦相似度可以作为补充，但不能单独用：删掉一半内容的转写仍可能拿到很高的相似度，所以必须与 $S/D/I$ 分解一起看——同样是 10% WER，全是替换和全是删除的下游结局完全不同。更硬的是下游任务成功率：语音 agent 的轮次任务完成率、订位/下单/病历的字段填充准确率、意图准确率。这类指标的口径与陷阱见 [[evaluation-10]]。

**④ 流式指标。** 流式产品的体验由四个量决定，而不是由最终 WER 决定：

- **首字延迟**（TTFW）= 首帧音频到第一个非空 partial 的时间；
- **句尾延迟** = VAD 判定语音结束到 final 转写的时间；
- **部分结果翻转率** = 把所有 partial 与 final 对齐后，最终被改写的词槽数 ÷ final 词数（可再分替换/删除/插入）；
- **稳定延迟** = 每个词最后一次被改写的时间相对语音结束的分布（报 p50 / p90）。

翻转率与延迟预算的关系、以及它如何影响打断体验，见 [[multimodal-03]]。

**⑤ 置信度与拒识。** 把句级置信度 $c_i$（平均 token 后验、归一化对数似然，或一个小的校准器输出）与句级错误率 $e_i$（归一化编辑距离）做成 risk–coverage 曲线：

$$\text{risk}(\tau) = \frac{\sum_i \mathbb{1}[c_i \ge \tau]\, e_i}{\sum_i \mathbb{1}[c_i \ge \tau]}, \qquad \text{coverage}(\tau) = \frac{1}{U}\sum_{i=1}^{U} \mathbb{1}[c_i \ge \tau]$$

要报的是「在可接受 risk 下的 coverage」，而不是 AUC 这类排序分；再乘上兜底动作的成本（重问一次、转人工、播报确认）才算收益。数值节的示例：82% 覆盖率时保留集 WER 2.1%，被拒的 18% WER 24.0%，整体 6.04%——这 18% 就是澄清与重问的预算。

### 3. TTS 为什么不能套用 WER 式指标：三个后果

**① 参考输出不唯一 → 编辑距离失效。** 同一句文本有无数条都正确的音频，时长、停顿、重音、音色都合法。序列级距离（例如 mel 上的 DTW）测的是「与某条参考录音有多像」，既惩罚合理的韵律差异，又只覆盖有录音的那批句子——而那批句子通常来自训练分布，等于自带污染。PESQ / STOI 这类**侵入式**指标需要参考信号，只适合「有同文本参考录音」的场景（声音转换、重合成、编解码评估），拿来评任意文本的自然度是错配。

**② 维度是多维的 → 单一分数掩盖权衡。** 神经 TTS 综述把系统拆成文本分析、声学模型、声码器三个组件，并把快速、低资源、鲁棒、表现力、自适应列为五个工程专题；综述正文把「自然且可懂」列为系统目标，并把 **word skipping（跳字）与 repeating（重复）** 明确列为影响音质的鲁棒性问题。这等于给出了评测的坐标轴：**好听程度**与**错误率**是两个独立的轴，再加上音色相似度、韵律可控性、稳定性。举个口径示例：系统 A 自然度 MOS 4.30、相似度 0.72，系统 B 自然度 4.10、相似度 0.86；只报一个总分，A 胜；产品是声音克隆，应该选 B。

**③ 主观评价昂贵且有偏。** MOS 的方差来自听者之间、听者之内、文本难度与录音链路；跨实验不可比的原因是听者群体（是否母语、是否筛听力）、回放设备、打分界面与锚点、指导语（问自然度还是问相似度）、样本量都不同；此外降噪、响度归一化、码率这类工程环节会直接抬分。**MOS 是仪器而不是真理**：只有同一协议内的相对大小有意义。

### 4. TTS 的评测组合（题眼）

**① 人工受控主观评测——校准层。** 协议要固定并写进评测卡：任务（自然度、说话人相似度、可懂度分维度问，不要合并成一个问题）、量表（ACR 式 5 分 MOS；7 分制 CMOS 给 −3 到 +3；ABX 二选一；MUSHRA 类 0–100 且带隐藏参考与锚点）、听者（目标语言母语者、听力筛查、耳机、每人听多少条）、材料（系统 × 文本 × 说话人的交叉设计，随机化、盲测）、统计（报均值 + 置信区间；系统间比较用成对检验或 bootstrap；多系统比较做多重比较校正）。成对优于绝对打分的量化理由见「数值与代码验证」，同一条结论也是 judge 校准的起点（[[evaluation-01]]）。

**② 客观代理——回归层。**

| 代理指标 | 怎么算 | 失效模式 / 必做的对照 |
| --- | --- | --- |
| 说话人相似度 | 说话人验证嵌入的余弦 $\cos(\mathbf{v}_{\text{syn}}, \mathbf{v}_{\text{ref}})$，或按验证系统 EER 阈值折算成「判为同一人」的通过率 | 复制、拼接参考音频即可刷满；参考录音要选未参与训练的，并做波形级重复检测 |
| 可懂度 | 用 ASR 反测合成语音的 WER / CER，或用强制对齐算音素错误率 PER | ASR 的语言先验会把发音错误改回正确词，指标偏乐观；对韵律无感。必要时换无 LM 的声学/音素级识别 |
| 韵律与时长 | F0 均值 / 标准差（半音）、语速、停顿时长的分布，与参考分布比 KS 或 Wasserstein 距离 | 只比均值会漏掉「均值正确、方差塌缩」的单调感；要比分布 |
| 发音错误率 | 强制对齐到目标音素序列，统计错读音素占比 | 依赖发音词典与对齐器；专有名词需要自定义 G2P |
| 神经质量打分 | 用语音语言模型当判别器或打分器 | StyleTTS 2 的口径是：用大规模语音语言模型（WavLM）做判别器，在 LJSpeech 上由英语母语听者评测**超过真人录音**、在 VCTK 上**与真人持平**，论文称这是首次在单说话人与多说话人数据集上达到人类水平。这是「用模型评价模型」的实例，但结论限定于这两个数据集与母语听者条件，外部有效性仍要在自己的评测集上验证 |

**③ 错误与安全——红线层。** 跳字与重复率、语种混淆率（分段跑语言识别，看是否读错语种）、长文本截断/静音异常、异常重复循环；音色克隆的授权、同意与滥用防护属于发布红线，不达标时其他指标没有意义（[[safety-10]]、[[safety-07]]）。

**④ 延迟与稳定性——产品层。** 首包延迟 TTFB、实时因子 $\text{RTF} = T_{\text{合成耗时}} / T_{\text{音频时长}}$（小于 1 才可能流式实时），以及长文本稳定性：按 10 秒窗口算说话人相似度与 F0 统计，报斜率与最差窗口，用来抓「越读越不像」的漂移。chunking 与 jitter buffer 如何决定这些量的下限，见 [[multimodal-08]]。

### 5. 落地纪律

- **分工**：几百条规模的人工受控评测（成对设计）做校准 → 大规模自动代理指标做回归门禁（[[evaluation-04]]）→ 下游任务指标做最终仲裁（[[evaluation-10]]）→ 全程按语言、口音、信道、文本类型分群报告。
- **通用原则**：任何自动指标上线前，先在留出集上验证它与人工判断的相关性——Spearman / Kendall 相关系数，以及用于选型时更重要的「成对方向一致率」（指标判 A 优于 B 的方向与人工判断一致的比例）。SLT 2022 那项工作的结构就是这件事的先例：先造带人工判断的参考基准，再筛指标，最后才敢推荐。缺这一步，等于在优化一个未知目标；judge 的校准方法可直接借用（[[evaluation-01]]）。
- **三条工程纪律**：口径版本化（归一化规则、分词器、ITN 词典、权重表都进版本管理，指标数字必须能追溯到版本）；评测集不回流训练，音频侧还要查近重复（[[evaluation-06]]）；任何对外数字都附样本量、置信区间与分群。

## 数值与代码验证

四篇参考资料都没有给出可直接复算的算式，以下数字全部按本节声明的假设自行复算；论文只贡献结论口径（见最后一节）。

**归一化口径如何改变同一个模型的 WER。** 参考 `Um, so the total is twenty three dollars, right?`，假设 `so the total is 23 dollars right`：

| 口径 | 参考词数 | 编辑距离 | WER |
| --- | --- | --- | --- |
| 原样（保留标点与大小写、不去填充词） | 9 | 5 | 55.6% |
| 去标点 + 小写 + 去填充词 | 8 | 2 | 25.0% |
| 再加 ITN（twenty three → 23） | 7 | 0 | 0.0% |

**同一个 WER，不同的业务后果。** 参考 `book a table for four at seven pm at the ritz`（11 词）：

| 假设 | 编辑距离 | WER | 实体准确率 | 后果 |
| --- | --- | --- | --- | --- |
| `... at the writs` | 1（替换） | 9.09% | 2/3 | 店名错，任务失败 |
| `... at the ritz please` | 1（插入） | 9.09% | 3/3 | 无信息损失 |

**micro 与 macro。** 两句评测：100 词错 10（10%）、10 词错 5（50%）。语料级 micro $= 15/110 = 13.64\%$，逐句 macro $= (10\%+50\%)/2 = 30.0\%$。报哪个都可以，但两个口径差 2.2 倍，必须写明。

**分群与流量重加权。** 20,000 词、1,000 句的评测集：

| 群 | 句数 | 词数 | 错误 | WER |
| --- | --- | --- | --- | --- |
| A（近讲标准口音） | 800 | 16,000 | 480 | 3.0% |
| B（远场 + 口音） | 200 | 4,000 | 560 | 14.0% |
| 合并 | 1,000 | 20,000 | 1,040 | 5.2% |

最差组与最好组之比是 $14.0/3.0 = 4.67$ 倍（最差组相对总体为 $14.0/5.2 = 2.69$ 倍）；若线上流量里 B 占 40%，预期 WER 是 $0.6 \times 3.0\% + 0.4 \times 14.0\% = 7.4\%$。

**WER 的置信区间与所需数据量。** 把每个词近似看作独立伯努利试验（真实因为句内错误相关而更宽，见下方 bootstrap）：

| 目标 | 公式 | 结果 |
| --- | --- | --- |
| $p=1.8\%$、$N=12{,}000$ 词的 95% CI | $p \pm 1.96\sqrt{p(1-p)/N}$ | $[1.56\%, 2.04\%]$（半宽 0.238%），12,000 词 ≈ 80 分钟（按 150 词/分） |
| 检出 1.8% vs 2.3% | $n = (z_{1-\alpha/2}+z_{1-\beta})^2\frac{p_1(1-p_1)+p_2(1-p_2)}{(p_1-p_2)^2}$ | 每组 12,605 词 ≈ 84 分钟 |
| 检出 1.8% vs 2.2% | 同上 | 每组 19,226 词 ≈ 128 分钟 |

**主观评测的样本量。** 假设单条语音的单听者打分标准差 $\sigma = 0.6$（5 分制，需自己在预实验里测）、同一听者对两条语音打分的相关系数 $\rho = 0.65$，$\alpha = 0.05$、power 80%：

| 设计 | 公式 | 检出 0.2 / 0.1 / 0.05 分所需 |
| --- | --- | --- |
| 绝对 MOS（半宽 $\delta$） | $n = (1.96\sigma/\delta)^2$ | 35 / 139 / 554 条评分 |
| 成对 CMOS（均值差 $\Delta$） | $n = \frac{(z_{1-\alpha/2}+z_{1-\beta})^2 \sigma_d^2}{\Delta^2}$，$\sigma_d = \sigma\sqrt{2(1-\rho)} = 0.502$ | 50 / 198 / 792 对 |
| 非配对对照 | $n = \frac{2(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2}{\Delta^2}$ | — / 566 条每组 / — |

同样检出 0.1 分，配对 198 对 vs 非配对每组 566 条，效率约 2.86 倍——这就是「成对优于绝对打分」的量化理由。ABX 这类二选一任务另算：要证明正确率 60% 显著高于猜测 50%，需要 194 次试次；正确率 70% 时降到 47 次。

**拒识的收益。** 1,000 句、整体 WER 6.04%：置信度阈值取在覆盖率 82% 时，保留集 WER 2.1%，被拒的 180 句 WER 24.0%。这 180 句就是重问 / 转人工 / 让用户确认的预算，值不值要用兜底动作的成本算。

```python
import math, random, re

def lev(ref, hyp):
    """最小编辑距离 = S + D + I"""
    d = [[0] * (len(hyp) + 1) for _ in range(len(ref) + 1)]
    for i in range(len(ref) + 1):
        d[i][0] = i
    for j in range(len(hyp) + 1):
        d[0][j] = j
    for i in range(1, len(ref) + 1):
        for j in range(1, len(hyp) + 1):
            cost = 0 if ref[i - 1] == hyp[j - 1] else 1
            d[i][j] = min(d[i - 1][j] + 1, d[i][j - 1] + 1, d[i - 1][j - 1] + cost)
    return d[len(ref)][len(hyp)]

def tokens(text, lower=True, drop_fillers=True):
    ts = re.sub(r"[^\w\s]", " ", text).split()      # 归一化第 1 步：去标点
    if lower:
        ts = [t.lower() for t in ts]                # 归一化第 2 步：小写
    if drop_fillers:
        ts = [t for t in ts if t not in {"um", "uh", "er"}]
    return ts                                       # 归一化第 3 步：ITN 另接一个词典

def boot_ci(rows, n_boot=2000, seed=0):
    """rows = [(len(tokens(r)), lev(tokens(r), tokens(h))) for r, h in pairs]。
    按句重采样——错误在句内相关，按词重采样会低估区间宽度。"""
    rng = random.Random(seed)
    out = []
    for _ in range(n_boot):
        s = [rows[rng.randrange(len(rows))] for _ in rows]
        out.append(sum(e for _, e in s) / sum(n for n, _ in s))
    out.sort()
    return out[int(0.025 * n_boot)], out[int(0.975 * n_boot) - 1]

Z_A, Z_B = 1.959964, 0.841621          # 双侧 alpha=0.05、power=80%

def n_abs_mos(sigma=0.6, half_width=0.1):
    return math.ceil((Z_A * sigma / half_width) ** 2)

def n_paired(sigma=0.6, rho=0.65, delta=0.1):
    sigma_d = sigma * math.sqrt(2 * (1 - rho))
    return math.ceil((Z_A + Z_B) ** 2 * sigma_d ** 2 / delta ** 2)

def n_abx(p1=0.6, p0=0.5):
    num = (Z_A * math.sqrt(p0 * (1 - p0)) + Z_B * math.sqrt(p1 * (1 - p1))) ** 2
    return math.ceil(num / (p1 - p0) ** 2)

def paired_bootstrap_ci(diffs, n_boot=2000, seed=0):
    """diffs：每条语音上「系统 A 的听者均分 − 系统 B 的听者均分」"""
    rng = random.Random(seed)
    means = sorted(sum(diffs[rng.randrange(len(diffs))] for _ in diffs) / len(diffs)
                   for _ in range(n_boot))
    return sum(diffs) / len(diffs), means[int(0.025 * n_boot)], means[int(0.975 * n_boot) - 1]

def synth_corpus(n_sent=500, seed=7):
    """合成语料 (词数, 错误数)：句长 12–36 词，8% 的句子带 2–9 个错误，故错误在句内聚类"""
    rng = random.Random(seed)
    rows = []
    for _ in range(n_sent):
        n = rng.randint(12, 36)
        rows.append((n, rng.randint(2, 9) if rng.random() < 0.08 else 0))
    return rows

def synth_diffs(n=200, seed=11):
    """合成配对打分：每条语音上「A − B」的听者均分差 ≈ N(0.12, 0.5)"""
    rng = random.Random(seed)
    return [rng.gauss(0.12, 0.5) for _ in range(n)]

if __name__ == "__main__":
    rows, d = synth_corpus(), synth_diffs()
    nw, ne = sum(n for n, _ in rows), sum(e for _, e in rows)
    print(f"WER={ne / nw:.2%} 二项半宽={1.96 * math.sqrt(ne / nw * (1 - ne / nw) / nw):.3%}")
    print(f"bootstrap={boot_ci(rows)} 配对={paired_bootstrap_ci(d)}")
    print(f"胜 {sum(x > 0.05 for x in d)} 负 {sum(x < -0.05 for x in d)} 平 {sum(abs(x) <= 0.05 for x in d)}")
```

直接运行上面代码块（`python3` 执行 `__main__`）：合成语料（seed=7、500 句、错误在句内聚类）WER 2.65%，词级独立假设的二项近似给 ±0.291%，换成按句 bootstrap 是 $[1.98\%, 3.38\%]$、半宽 0.697%，**宽了 2.39 倍**——这正是「WER 的误差棒必须按句聚类」的理由；合成的配对打分（seed=11、200 条）均值差 +0.196、bootstrap 95% CI $[+0.123, +0.267]$，胜 127 / 负 61，其余 12 条落在死区 ±0.05 内，CI 不含 0 才敢说改进成立。

## 常见追问

- **追问**：为什么论文里的 MOS 不能横向比较？
  - 要点：听者群体（母语 / 非母语、是否筛听力）、回放设备与噪声环境、打分界面与锚点、指导语（问自然度还是相似度）、样本量、是否含隐藏参考与锚点，任何一项不同尺度就漂移；MUSHRA 类协议之所以要隐藏参考与锚点，就是给分数提供一个实验内的绝对支点。跨论文只能比较**协议内**的相对排序。
- **追问**：怎么防 ASR / TTS 评测集污染？
  - 要点：文本侧查 n-gram 重叠；音频侧查近重复（感知哈希、嵌入近邻），TTS 还要看模型能否近乎复现参考波形（相似度异常接近 1 是记忆信号）；评测集不回流训练、访问受限、定期轮换；对外报告写明数据版本（[[evaluation-06]]）。
- **追问**：流式 ASR 的部分结果怎么评？
  - 要点：至少三个量——首字延迟、句尾延迟、部分结果翻转率（最终被改写的词槽 ÷ final 词数），再加稳定延迟的 p50 / p90。翻转率高的系统即使最终 WER 一样，用户也会觉得「它在乱猜」。
- **追问**：用 ASR 反测合成语音的 WER 当可懂度指标，坑在哪？
  - 要点：ASR 的语言先验会把错读改回正确词（指标偏乐观）；它对韵律、重音、情绪不敏感；参考文本若是训练语料的一部分还会互相污染。要用无 LM 的声学 / 音素级识别或 PER 作为对照，并单独评韵律。
- **追问**：说话人相似度高就说明克隆好吗？
  - 要点：不一定，复制或拼接参考音频即可刷满；参考录音要选未参与训练的，并做波形重复检测、文本一致性（ASR 反测）与人工抽检；相似度只覆盖音色，覆盖不了韵律与自然度。
- **追问**：0.1 分的 MOS 差异值得为它发版吗？
  - 要点：先算 CI——绝对打分要 139 条独立评分才能把半宽压到 ±0.1，成对比较 198 对；如果现有数据只有几十条，0.1 分在噪声里。真要做决策，用同一批听者对同一批文本的成对比较，而不是把两次独立 MOS 相减。
