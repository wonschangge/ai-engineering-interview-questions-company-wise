## 这个专题的知识地图

按数据流顺序，12 道题正好覆盖一条流水线：

| 阶段 | 题目 | 关键判断 |
| --- | --- | --- |
| 语料解析与切分 | 01、10 | 结构感知切分；表格/图表/多栏 PDF 的解析质量是上限 |
| 召回 | 02、05、09 | 稀疏与稠密互补；查询改写可选；ANN 索引用 recall 目标反推参数 |
| 排序与上下文 | 03 | 两阶段漏斗，cross-encoder 精排，候选数受延迟约束 |
| 生成与可验证 | 12 | 论断级归因 + 后验校验，引用覆盖率与正确率同看 |
| 质量与运维 | 04、07、11 | 分层评估、漂移检测、索引新鲜度三个 SLO |
| 安全与形态 | 08、06 | 权限在召回期强制；agentic 只给多跳任务用 |

**建议顺序**：`01 → 02 → 03` 是检索主线（切分 → 召回 → 重排），面试里最常连着问；
`04 → 07 → 11` 是运维主线（怎么知道它坏了、怎么发现它悄悄变坏、怎么让它跟上数据）；
`08` 与 `12` 是企业级场景的加分项（权限与可验证性），`06` 是难度最高的一题。

## 谁在问这个专题

按 `README.md` 的统计，本专题的题目出现在 9 家公司的面试中：**Perplexity（4 题）** 集中在检索质量、索引新鲜度与引用归因；
**Glean、Microsoft、Cohere（各 3 题）** 覆盖 chunking、hybrid 检索、重排、评估与权限；
**Databricks、Palantir** 问权限感知检索；**Harvey、Abridge** 问答案归因（法律与医疗场景对可验证性的要求最高）；
**Cursor** 问索引新鲜度。
