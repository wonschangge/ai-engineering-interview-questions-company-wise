## 2. 如何使用这个仓库

- 首先从“Common Questions Asked Across Companies”开始复习，这部分是跨公司高频问题。
- 然后按目标公司定位，阅读各公司的章节。
- 每个题目都尽量给出参考答案或相关文章链接，便于快速补足知识面。
- 面试技巧：把题目当作知识地图，而不是死记硬背；更重要的是能讲出原理、设计和 trade-off。

## 5. 建议学习路线

### 入门路线

1. Transformer 基础：Attention、Multi-head、Positional Encoding、RoPE
2. LLM 训练与推理：KV Cache、Prefill/Decode、量化、Batching
3. RAG：检索、重排、评估与权限控制
4. Agent：ReAct、Function Calling、MCP、tool use、主循环设计
5. 评估：LLM-as-a-Judge、hallucination、A/B 测试

### 进阶路线

1. MoE、长上下文、Mixture-of-Experts
2. 推理优化：PagedAttention、vLLM、SGLang、TensorRT-LLM
3. 后训练：RLHF、DPO、GRPO、RLAIF
4. 安全：Prompt Injection、Guardrails、PII、红队评估
5. 多模态与语音：VLM、ASR、TTS、实时语音 Agent
